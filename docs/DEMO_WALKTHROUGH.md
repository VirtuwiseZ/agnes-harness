## 二、 推荐演示命题（可直接复制提交）

系统具备任务自识别能力。当题干中包含物理推导、数值求解或方程建立等特征时，系统会自动激活物理分析流水线。

### 演示命题一：天体轨道力学与深空飞越动量交换分析
该命题考察智能体在连续常微分方程数值求解、多天体参数对比以及守恒定律检验方面的表现：

> **推荐输入题干**：  
> “前往外太阳系的航天器通常会使用引力辅助机动。当航天器到达木星等外行星时，它必须减速才能进入轨道，这可能会消耗大量的燃料。有人认为，抵达木星附近的航天器可以利用木星的卫星进行引力辅助机动，从而节省入轨所需燃料。请评估对于一个以 20 公里/秒的速度抵近木星系统的航天器，这个策略是否可以节省大量燃料。”

- **智能体执行预期**：
  1. 自动从权威公开资料库中调取木星引力常数及四颗伽利略卫星的轨道半长轴；
  2. 建立双曲轨道偏折角与速度变化模型，现场编写 Python 脚本计算各卫星的减速上限；
  3. 执行物理单位检查与极端情况检验（如零引力场下减速严格为零）；
  4. 结合火箭推进剂方程计算燃料节省比例，给出客观严谨的学术结论；
  5. 自动绘制多卫星对比图表并输出完整的单文件离线研究报告。

### 演示命题二：经典波动光学衍射场分布与仪器极限分辨本领
该命题考察智能体在从基本定律进行闭式数学解析推导、微观/宏观跨尺度模型建立方面的表现：

> **推荐输入题干**：  
> “请系统分析波动光学中衍射与光学分辨本领的核心问题，完成控制方程推导、量纲与极限验证、数值仿真作图，并形成严谨规范的研究报告：  
> 1. 推导夫琅禾费单缝衍射的光强分布公式，分析白光入射时的色散规律与条纹角宽度；  
> 2. 从圆孔衍射与第一类贝塞尔函数极值出发，推导艾里斑角半宽度与瑞利判据公式；  
> 3. 结合人眼实际参数（瞳孔直径 2.5 mm，波长 550 nm），推导人眼极限分辨角，并计算航天员在离地 200~400 km 轨道高度时肉眼对地面的极限分辨线间距，对比长城实际尺寸（5~8 米），给出物理上人能否在太空中凭肉眼分辨长城的结论；  
> 4. 推导普通光学显微镜的阿贝衍射极限公式，评估在浸油物镜极限数值孔径（NA ≈ 1.4）下的最高空间分辨率。”

- **智能体执行预期**：
  1. 从惠更斯-菲涅耳面元积分推导出单缝 sinc^2 光强分布，并解释中央白光与高级次彩条的色散机理；
  2. 求解贝塞尔函数第一非零零点（约 3.8317），推导出瑞利判据并在数值上验证两峰重合中心光强凹陷约 73.5%；
  3. 计算出 200~400 km 轨道高度肉眼对地分辨率为 53.7~107.3 米，从物理定律和生理尺度严密论证肉眼看长城的不可能性；
  4. 给出显微镜空间分辨率极限（约 0.2 微米），并生成四张无遮挡矢量图表与学术报告。

## 三、 端到端运行实操步骤

如果您选择“途径 B”进行新会话实跑，操作流程如下：

### 步骤 1：拉起前台工作台
双击根目录下的 **`一键启动.bat`**（或执行 `powershell -File scripts/start.ps1`）。浏览器将自动打开：`http://127.0.0.1:4180`。

### 步骤 2：新建会话与选定工作区
1. 点击左上角的 **新建会话 (New Session)**；
2. 在左侧工作区列表中，选择系统默认配置的独立工作区目录（默认为 `agh-workspace` 或 `E:\agh-test`）；
3. 确保当前工作区包含 `.agh/skills/` 技能目录。

### 步骤 3：提交题干并观察自主分析
将上方任一推荐题干粘贴至输入框中，按回车发送。  
*智能体将依次执行：*
- 识别物理任务特征，由流程路由器按需引导加载专业子技能；
- 提炼一句话核心目标并进行数量级估算；
- 现场编写用于微分方程求解或面元积分的 Python 脚本。

### 步骤 4：响应外部代码执行审批
当系统需要调用外部本地 Python 执行计算时，页面右下角会弹出**命令执行审批卡片**（明确显示即将运行的 Python 命令与参数）。  
- 点击 **允许一次 (allow_once)** 授权执行；
- 外部独立的 Python 解释器将在沙箱环境中实际运行求解，并将真实的终端输出与退出码返回给智能体继续分析。

> **安全机制说明**：凡涉及操作系统命令执行与文件改动，系统均强制要求人类用户审批，坚决杜绝大模型私自口算或越权执行。

### 步骤 5：检阅交付成果
计算与检验完成后，智能体会在会话窗口第一段直接交付两个本地成果文件路径：
1. **纯文本 Markdown 报告源码（`report.md`）**：方便后续学术引用与公式提取；
2. **单文件离线交互式 HTML 报告（`research_report_...html`）**：用于完整成果查验与交互复核。

## 四、 离线 HTML 报告核心交互功能说明

用浏览器双击打开生成的 HTML 报告，可以体验专为科学研究设计的多项交互能力：

1. **双栏联动视窗**：
   - **左侧主报告**：规范学术排版，数学公式由本地内联代码渲染（完全脱网可用），矢量图表采用外置图例条，确保数据曲线 100% 零遮挡；
   - **右侧执行账本**：完整展示底层每一次工具调用的入参、终端回显、耗时以及时序甘特图。
2. **侧边栏自由拖拽缩放**：
   - 鼠标按住右侧窗格的左边缘手柄，可在 340 像素至 1100 像素以上自由拉伸宽度；
   - 顶部提供四档常用宽度预设（480px / 640px / 800px / 50% 均分），自适应不同分辨率屏幕。
3. **日志自动换行开关**：
   - 点击右侧顶部的【自动换行 / 保持单行】按钮，长命令与多行输出即可完整折行展开，避免水平滚动。
4. **正文蓝链毫秒级热跳转（Hot Jump）**：
   - 正文中的数据结论、调试记录均配有可点击的蓝色链接；
   - 点击任意蓝链，右侧时序列表会自动平滑滚动居中并触发脉冲高亮，方便读者直接核查支撑该结论的真实代码与运行日志。
5. **跨标签页无重载唤回**：
   - 点击报告右侧顶部的“返回对应的 AGH 页面查看”按钮，能够利用浏览器通信机制无缝唤回前台会话窗口，无需重新刷新页面。
