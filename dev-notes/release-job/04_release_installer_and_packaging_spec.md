## 一、 设计目标与用户痛点分析

在面向开源社区发布 GitHub Release 安装包时，不同终端用户的本地计算机环境具有高度的异构性与不确定性：
1. **痛点 1：缺少 Node.js 或版本过低**：部分科研或高校用户可能主要使用 Python，本地未预先配置 Node.js 24 或全局 pnpm；
2. **痛点 2：Python 依赖缺失或处于网络受限环境**：用户可能安装了裸 Python，但缺少 SymPy、Pint、NumPy、SciPy、Matplotlib 等计算库，且可能因内网环境无法顺畅执行 `pip install`；
3. **痛点 3：配置繁琐、启动路径长**：传统项目往往要求用户手动敲打多条复杂的命令行与环境变量，容易因一步操作失误导致放弃；
4. **痛点 4：污染宿主环境与端口冲突**：若直接复用默认开发配置，可能导致默认端口（如 4177）被冲突占用，或生成的数据文件散落在用户根目录。

为解决上述痛点，本项目设计了**免门槛、向导式、支持自检与容错的一键安装与部署体系**。

## 二、 部署工具矩阵与架构分工

系统提供“双击批处理（面向 Windows 桌面用户）”与“纯命令行脚本（面向全平台终端用户）”双层架构：

| 工具脚本 | 入口形式 | 核心执行职责 | 容错与兜底机制 |
| :--- | :--- | :--- | :--- |
| **`scripts/doctor.ps1`**<br>`环境自检.bat` | 双击运行 / 命令行调用 | **只读环境诊断**：<br>• 检测 64 位操作系统架构；<br>• 检测 Node.js 是否就绪（是否满足 `>=24.10` 基线）；<br>• 检测 pnpm 是否就绪；<br>• 检测 Python 及 5 项核心科学库状态；<br>• 输出健康度汇总报告。 | **纯只读模式**：不修改本地任何文件或环境变量，只输出诊断结果与指引，安全无副作用。 |
| **`scripts/setup.ps1`**<br>`一键安装.bat` | 双击运行 / 命令行调用 | **一键安装与构建向导**：<br>1. 检查 Node.js，若无全局 pnpm 自动调用 Corepack 激活；<br>2. 支持创建指定或默认隔离工作区（`agh-workspace`）；<br>3. 执行 `pnpm install` 依赖解析；<br>4. 检测 Python 科学库，必要时自动尝试 `pip install`；<br>5. 执行 `@agnes/cli` 本地构建；<br>6. 执行技能文件编码合规核验。 | **多层依赖兜底**：<br>• pnpm 离线优先，失败自动在线重试；<br>• Python 联网 pip 失败时自动提示调用内置便携运行时与 wheels 离线包。 |
| **`scripts/start.ps1`**<br>`一键启动.bat` | 双击运行 / 命令行调用 | **极速服务启动器**：<br>1. 检查构建产物，缺失时自动无缝唤起安装；<br>2. 将技能与业务资产同步至工作区；<br>3. 检查端口（默认 `4180`），优雅终止旧僵尸进程；<br>4. 设置专用 `$env:AGH_HOME = ~/.agh-physics` 隔离目录；<br>5. 拉起后台守护服务并自动调起默认浏览器访问。 | **端口与环境硬隔离**：<br>使用专用数据目录与独立端口，绝对不干扰宿主机上已有的 4177 或其他默认开发环境。 |

## 三、 面向 GitHub Release 的标准压缩包结构规划

发布至 GitHub Releases 的预构建源码包（如 `physics-agent-v1.0.0.zip`），其顶层目录组织如下：

```
physics-agent-release-root/
├── 一键安装.bat                  # [推荐入口] Windows 用户首次运行一键配置
├── 一键启动.bat                  # [推荐入口] Windows 用户日常一键拉起服务与浏览器
├── 环境自检.bat                  # [排查入口] 随时双击诊断环境健康状态
├── README.md                     # 项目中文主页说明（脱敏、客观、无竞赛黑话）
├── docs/                         # 用户使用文档体系
│   ├── INSTALL_GUIDE.md          # 详细安装、依赖排查与跨平台使用指南
│   ├── DEMO_WALKTHROUGH.md       # 独立经典物理分析 Demo 演示运行手册
│   └── ARCHITECTURE.md           # 系统架构设计与模块分工技术文档
├── scripts/                      # 核心自动化 PowerShell 脚本
│   ├── doctor.ps1                # 环境诊断逻辑实现
│   ├── setup.ps1                 # 安装与构建向导实现
│   └── start.ps1                 # 服务管理与启动逻辑实现
├── .agh/skills/                  # 10 个标准原生工作区技能
├── physics-agent/                # 业务核心资产（hooks/knowledge/plugins/runtime）
│   ├── hooks/                    # 物理门禁与报告编译脚本
│   ├── knowledge/                # 物理方法论与 reference_data 权威参考库
│   ├── plugins/                  # 原生路由器插件
│   └── third_party/portable-runtime/ # 便携运行时规范与依赖 wheels 目录
├── packages/                     # Agnes Harness 官方平台源码（含通用加固修复）
├── package.json                  # 项目依赖元数据
└── pnpm-workspace.yaml           # monorepo 仓库定义
```

## 四、 零门槛发布包的核心优势

1. **上手门槛极低**：Windows 用户下载解压后，**两步即可运行**（双击“一键安装” $\to$ 双击“一键启动”）；
2. **环境自适应**：智能自检 Node.js 与 Python 环境，遇到缺少依赖时自动尝试修复（Corepack 启用、pip 自动安装、便携运行时兜底），并在终端提供清晰下载链接；
3. **环境绝对隔离**：通过独立的数据主目录与端口管理，确保测试和日常使用不污染用户的系统全局环境，做到即插即用、卸载只需直接删除文件夹。
