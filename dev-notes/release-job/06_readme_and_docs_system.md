## 一、 文档体系设计原则与语言风格约束

根据开源项目发布标准与本次交付要求，面向最终用户与开源社区的所有文档均严格执行以下设计约束：
1. **纯中文编写（单一语言）**：不采用中英文双语混排，避免双重维护成本与上下文割裂；
2. **平实严谨、杜绝黑话**：通篇采用标准大学物理学与软件工程公认词汇，彻底剔除自造词与宣传包装辞藻；
3. **彻底脱敏与中立性**：
   - 不包含任何竞赛命题代号（如 UPC、2013A、2023、2025B 等内部测试标签）；
   - 不包含任何黑客松评审、答辩、比赛结题等临时性场景词汇；
   - 不暴露任何开发者个人隐私数据（姓名、学号、私人邮箱等）；
4. **互联互通、消除死链**：所有文档均建立自包含的相对路径超链接，形成有机闭环。
