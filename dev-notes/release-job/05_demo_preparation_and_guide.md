## 一、 演示案例设计原则与脱敏要求

为了使发布的开源项目具备独立、清晰、免配置的演示体验，项目演示案例的设计遵循以下准则：
1. **彻底脱敏与中立性**：
   - 彻底剥离任何具体竞赛命题代号（如 2013A、2023、2025B、UPC 等内部研发标签）；
   - 题目表述完全采用通用的经典物理学与天体动力学学术语言；
   - 不包含任何竞赛评审、黑客松答辩等临时性上下文。
2. **数理严谨与闭环代表性**：
   - 案例必须能够完整激活并检验工作站的全部核心能力：第一性解构、常数库调取、代码现场编写与求解、量纲与边界检验、以及离线双栏学术报告生成；
   - 案例必须具备确凿的物理理论支撑，杜绝使用无解或仅凭常识判断的概念型题目。
3. **双路径体验支持**：
   - 支持“即开即览”：用户无需大模型 API 凭据，直接双击随包附带的预生成 HTML 报告即可体验排版与交互；
   - 支持“端到端全流程运行”：提供开箱即用的题干文本，用户粘贴后即可观察智能体自主解题与人类审批机制。

## 二、 确立的两大通用演示案例

在 `docs/DEMO_WALKTHROUGH.md` 中，项目确立并提供了两套不同物理分支的经典案例：

### 1. 案例一：天体轨道力学与深空飞越动量交换分析（宏观连续数值模拟）
- **物理内涵**：评估高速抵近外行星的航天器能否通过多卫星引力借力机动实现闭合捕获及节省燃料；
- **能力体现**：
  - 自动调取 JPL / IAU 官方常数库；
  - 编写求解开普勒双曲轨道偏折角与齐奥尔科夫斯基推进剂消耗的 Python 脚本；
  - 运行零引力退化极限门禁（$G \to 0 \implies \Delta v \to 0$）；
  - 产出高分辨率矢量图表与学术报告。

### 2. 案例二：经典波动光学衍射场分布与仪器极限分辨本领（微观/宏观跨尺度解析推导）
- **物理内涵**：从麦克斯韦标量波衍射积分推导单缝衍射 sinc^2 分布与白光色散，推导第一类贝塞尔函数极值与艾里斑半角宽，结合人眼与微观显微镜参数推导演算极限分辨距离；
- **能力体现**：
  - 从第一性物理定律展开闭式数学解析积分；
  - 面元数值干涉叠加与解析闭合解的交叉验证（残差小于 0.2%）；
  - 宏观天文地空对地观测与微观油镜阿贝极限的跨尺度建模；
  - 产出四张科学矢量图表与符合规范的科技报告。
