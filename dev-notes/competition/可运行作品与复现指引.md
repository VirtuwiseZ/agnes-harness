## 二、 运行环境与系统依赖说明

### 1. 操作系统与硬件支持
- **测试验证系统**：Windows 11 x64 / Windows 10 x64（官方测试环境，提供专用 PowerShell 启动脚本）；
- **跨平台兼容**：架构基于标准 Node.js 与跨平台 Python 编写，同样兼容 macOS 12+ (Apple Silicon / Intel) 及 Linux (Ubuntu 20.04+ / Debian 11+)；
- **最低硬件配置**：单核 CPU、2 GB 可用内存、1 GB 可用磁盘空间（无重型 GPU 要求，物理求解与绘图均为轻量 CPU 高精度算法）。

### 2. Node.js 宿主底座环境
- **Node.js 运行时**：推荐 `Node.js >= 24.10`（官方实测版本为 `v24.21.0`）；
- **包管理器**：`pnpm 10.34.5`（可通过 Node 24 自带的 Corepack 直接启用：`corepack enable && corepack prepare pnpm@10.34.5 --activate`）。

### 3. Python 科学计算运行时（双轨环境保障）
为确保评审时无论目标主机是否安装过 Python，系统均能正常调用科学计算库，本项目设计了**双轨运行保障**：
- **轨道 A（系统原生 Python）**：若宿主机已配置 Python 3.10+，系统将优先检测并调用宿主环境；
- **轨道 B（免安装便携运行时 Portable Runtime）**：
  - 存放路径：`physics-agent/third_party/portable-runtime/`；
  - 运行时版本：官方无安装器、不碰系统注册表的 **嵌入式 Python 3.13.9 (embed-amd64)**；
  - 预烘焙 wheels 依赖（版本锁定）：
    - `sympy==1.14.0`（符号代数与量纲解析）；
    - `pint==0.26.1`（物理单位制与量纲齐次性机器推导）；
    - `numpy==2.5.3` / `numpy==2.2.2`（多维数组与离散网格）；
    - `scipy==1.18.1` / `scipy==1.15.1`（变步长微分方程数值积分与贝塞尔函数）；
    - `matplotlib==3.11.2` / `matplotlib==3.10.0`（出版级矢量图表生成）；
    - `plotly==7.1.0`（高维参数场交互图表支持）；
  - 字体支持：预置开源 CJK 矢量字体，保障在纯英文干净 Windows 系统下生成图表中文正常渲染、无方块豆腐块。

## 三、 大模型接入配置与调用方式

根据赛事规范，本项目所有智能推理环节均通过 AGH 平台的模型路由进行安全接入：

### 1. 模型名称与版本
- **官方指定基线模型**：**Agnes-3.0-Flash**（主推测与代码生成模型，由黑客松赛事平台统一授权管理）；
- **跨平台验证基准**：**Gemini-3.8-Flash**、**Claude-Opus-4.6-Thinking**（用于验证智能体在不同推理模型下的泛化稳定性）。

### 2. 凭据配置方式
- 在 AGH 网页前端（`http://127.0.0.1:4180` 或 `http://127.0.0.1:4177`）的 **设置 (Settings) ➔ 模型配置 (Models)** 中录入调用凭据；
- 所有凭据统一由 AGH 宿主底层基于 Windows 原生 DACL/ACL 保护的凭据库（Credential Store）进行加密存储，不会明文暴露在代码、对话或 Git 仓库中。

### 3. 严格的“非口算”工具调度模式
- 大语言模型在流水线中**仅负责概念解构、控制方程逻辑分析与 Python 代码编写**；
- 凡涉及方程求解、积分迭代、量纲比对与极限验证，模型必须且只能通过 AGH 原生提供的 `shell` 或专用 `tool` 接口发起调用；
- 计算全部交由外部独立 Python 解释器实际运行，返回确定性的标准输出（stdout/stderr）与退出码（exit code），模型依据机器回显继续推进。

## 四、 科学数据源与外部工具接口说明

为杜绝非物理的人工参数编造，本项目建立了规范化的外部数据接入与处理流程：

1. **天体力学常数体系**：
   - 数据源：NASA JPL Horizons 星历系统公开常数表、IAU 2015 天文物理常数；
   - 包含常数：木星引力常数 $G_J = 1.2669\times 10^8\ \text{km}^3/\text{s}^2$、木卫一至木卫四轨道半长轴（421,700 km ~ 1,882,709 km）、卫星质量比；
   - 获取方式：采用规范的 Level 2 离线权威常数表（`task_params.json`），免除对在线网络波动的依赖。
2. **基础物理公称常数**：
   - 数据源：CODATA 2022 推荐基础物理常数、标准大学物理教材公称参数；
   - 包含常数：真空光速 $c$、可见光中心波长（红650nm/绿550nm/蓝450nm）、人眼明视觉瞳孔公称孔径（3 mm）；
   - 获取方式：通过 `scipy.constants` 直接调用或离线常数表注入。
3. **网络异常诊断与自适应穿透接口**：
   - 当需要进行外部数据验证且宿主机开启了 TUN 虚拟网卡代理时，宿主工具可能拦截虚假公网段（`198.18.x.x`）；
   - 流水线自备 Python 底层套接字（Socket）轻量网络直连接口，直接穿透隧道获取真实数据，确保断网与代理环境下数据获取的鲁棒性。

## 五、 评委本地复现操作指南（以途径 2 为例）

以下是在评委主机上从零拉起测试服务并完成解题的完整操作步骤：

### 步骤 1：打开终端并进入项目目录
在 Windows 终端中打开 PowerShell，切换至项目所在目录：
```powershell
cd E:\agnes-harness
```

### 步骤 2：一键启动隔离测试环境（端口 4180）
执行自动化配置与启动脚本：
```powershell
.\start-test-runner.ps1
```
*脚本将按序自动完成：*
1. 检查并清理测试工作区历史题目结果，确保纯净无先验干扰；
2. 自动同步最新的 10 个 Skills、通用 Hooks 门禁与知识库至 `E:\agh-test`；
3. 自动扫描并清除技能文件的 UTF-8 BOM 标记，清除过期缓存；
4. 优雅停止旧测试守护进程，释放资源；
5. 在 4180 端口启动隔离测试服务。

### 步骤 3：浏览器访问测试工作台
控制台打印出 `Service Ready! -> http://127.0.0.1:4180` 后：
1. 打开浏览器访问：`http://127.0.0.1:4180`；
2. 在左侧工作区列表中选择：`E:\agh-test`（纯净测试工作区）；
3. 点击“新建会话（New Session）”。

### 步骤 4：提交测试课题
在会话输入框中粘贴待测试的物理课题，例如：

> **推荐测试课题 1（深空动力学工程探索）**：  
> “当探测器抵达外层行星（如木星）时，必须减速才能进入轨道，这一过程会消耗大量燃料。有观点认为，抵达木星的航天器可利用木星的卫星实施引力助推机动来减速，从而节省燃料。请评估，对于一个以 20 公里/秒的速度抵达木星系统的航天器，能否通过该策略实现显著的燃料节省。”

> **推荐测试课题 2（大学物理课内多问严密推导）**：  
> “我正在学习大学物理的波动光学部分。请作为一项严谨的物理专题推导与定量研究，系统分析下列衍射与光学分辨本领的核心问题，完成控制方程推导、量纲与极限验证、数值仿真作图，并最终形成严谨准确的学术报告：1. 白光单缝衍射机理与色散；2. 光学仪器艾里斑与瑞利判据公式推导；3. 结合人眼实际参数（瞳孔 3mm，波长 550nm），推导 200~400km 轨道宇航员肉眼看长城地面极限分辨物宽，给出确定性物理判据；4. 普通光学显微镜阿贝衍射极限推导。”

### 步骤 5：交互审批与成果查看
1. 智能体启动后，自动由 `physics-agent-orchestrator` 引导进入六节点流水线；
2. 当弹出命令执行审批窗口时，点击“允许一次（allow_once）”批准脚本执行；
3. 执行完成后，智能体在会话窗第一段直接交付 `.html` 与 `.md` 文件的本地绝对路径；
4. 复制并在浏览器中打开该 HTML 路径，即可检阅带有双栏拖拽、Trace 轨迹联动、无遮挡矢量图表与Section 9自愈复盘的完整学术报告。
