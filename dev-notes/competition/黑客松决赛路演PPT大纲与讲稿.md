## 三、 评委问答（Q&A）防御预案速查卡（Top 5 必答题）

针对决赛答辩可能遇到的专家提问，整理标准回答要点：

### Q1：你们如何证明最终的减速结论（24.51 km/s）是智能体自己算出来的，而不是预设硬编码或事先抄了范文？
- **答辩要点**：
  1. **纯净分支与物理隔离（§5）**：在专门设立的 `ability-test7` 纯净测试分支中，已物理彻底剥离 `dev-notes/` 目录，工作区零先验参考，由全新空会话自主驱动；
  2. **机器账本可追溯**：在 HTML 报告右侧的会话轨迹中，可精确回溯至 `seq #2841`（初版公式符号颠倒，计算出负燃料消耗）和 `seq #2933`（edit 定向修正后定稿），每一次 `shell` 调用的输入参数、执行耗时与控制台输出均带有 SHA 哈希，真实保留了调试历程；
  3. **独立交叉验证**：结论通过了独立齐奥尔科夫斯基火箭公式计算，两套计算路径完全正交。

### Q2：Agnes Harness 在你们系统中承担了什么不可替代的作用？为什么普通 Python 脚本做不到？
- **答辩要点**：
  1. **不可篡改的时序存证**：AGH 提供了底层只读的 `trace.jsonl`，这是评委复核的法医学凭证，传统独立脚本无法自证执行过程未被人工干预；
  2. **状态机与长程上下文治理**：普通 LLM 在数十轮工具调用后容易产生上下文遗忘，AGH 结合 `problem_state.json` 实现了唯一事实源（SSOT）增量纳管与异常回滚；
  3. **非侵入式技能生态**：通过 10 大原生工作区 Skills 拓扑体系，将科研调度逻辑与业务计算解耦，实现开箱即用。

### Q3：如果题目换成波动光学或课内教学问题，你们这个工作站还能跑通吗？泛用性如何？
- **答辩要点**：
  1. **资产与参数解耦**：我们在知识库中收录了经典物理多领域的分析方法，模型与数据源完全解耦；
  2. **机制核验防“张冠李戴”**：Node 2a 的机制匹配机制确保当遇到新问题时，智能体不会盲目套用旧公式，而是根据题面条件动态推演方程；
  3. **教学多问泛用性已验证**：系统已成功跑通白光单缝衍射分布、瑞利判据极限分辨本领以及宇航员看长城证伪等多问推导教学命题，证明了良好的跨领域适应能力。

### Q4：你们提到的“真机运行自愈闭环”是否会增加系统开销？为什么不一开始就做对？
- **答辩要点**：
  1. 真实科学探索本质上包含试错过程，在处理复杂或前沿问题时，要求一次性写出完全正确的控制参数并不现实；
  2. 我们的自愈闭环（符号颠倒纠偏、边界模块路径修正、TUN 代理 Socket 穿透）受状态机明确约束，定位和修正仅需几步编辑操作；
  3. 敢于主动暴露并如实记录异常，正是工程严谨性的体现，明显优于为了掩饰错误而隐瞒或暗中手动篡改。

### Q5：你们的单文件 HTML 报告如何保证在无网络完全隔离环境下依然可用？
- **答辩要点**：
