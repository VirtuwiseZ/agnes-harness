## 三、 评委问答（Q&A）防御预案速查卡（Top 5 必答题）

针对决赛答辩可能遇到的专家提问，整理标准回答要点：

### Q1：你们如何证明最终的减速结论（24.51 km/s）是智能体自己算出来的，而不是预设硬编码或事先抄了范文？
- **答辩要点**：
  1. **物理隔离机制（§5）**：智能体在运行中受到治理协议的刚性约束，物理上严禁读取任何参考答案文件；
  2. **机器账本可追溯**：在 HTML 报告右侧的会话轨迹中，可精确回溯至 `seq #2841`（第 1 次调试符号反了，算出负值）和 `seq #2933`（第 2 次修改后定稿），每一次 `shell` 调用的输入参数、执行耗时与 `stdout` 截断均带有 SHA 哈希，真实保留了调试历程；
  3. **独立交叉验证**：结论通过了独立齐奥尔科夫斯基公式计算，两套计算路径完全正交。

### Q2：Agnes Harness 在你们系统中承担了什么不可替代的作用？为什么普通 Python 脚本或 LangChain 做不到？
- **答辩要点**：
  1. **不可篡改的时序存证**：AGH 提供了底层只读的 `trace.jsonl`，这是评委复核的法医学凭证，传统脚本无法自证未被篡改；
  2. **状态机与长程上下文治理**：普通 LLM 在数十轮工具调用后会严重遗忘或死循环，AGH 结合 `problem_state.json` 实现了单真实源（SSOT）增量纳管与配额退火回滚；
  3. **非侵入式插件生态**：通过 AGH 运行时插件与 Skill 机制，将科研调度逻辑与业务计算完美解耦。

### Q3：如果题目换成电磁学、热学或流体问题，你们这个工作站还能跑通吗？泛用性如何？
- **答辩要点**：
  1. **资产与参数解耦**：我们在知识库中收录了八大经典物理板块的工具谱系（刚体、流体、天体、热学、波动、电磁、标度律、优化），模型与数据源完全解耦；
  2. **机制核验防“张冠李戴”**：Node 2a 的机制匹配机制确保当遇到新问题时，智能体不会盲目套用旧公式，而是根据题面条件动态重构方程；
  3. **通用防线有效**：量纲齐次性门禁与极值退化门禁是所有物理分支普适的底层数学防线。

### Q4：你们提到的“四大工程返工自愈”是否会增加系统开销？为什么不一开始就做对？
- **答辩要点**：
  1. 真实科学探索本质上是非线性的试错过程，任何科学工作者都无法在陌生问题上一次性写出完美参数；
  2. 我们的局部退火机制设置了严格的配额管理（$N \le 3$），回滚只发生在必要时刻，平均重构耗时仅数秒；
  3. 敢于主动暴露并记录异常，正是工程可靠性成熟的标志，优于“为了成功率而隐瞒错误、暗中修改”。

### Q5：你们的单文件 HTML 报告如何保证在无网络完全隔离环境下依然可用？
- **答辩要点**：
  1. 彻底剔除所有 `jsdelivr` 等外部在线 CDN 链接；
  2. 数学公式排版采用内嵌的 `#katex-inline-style` 离线样式与预编译语义 DOM；
  3. 图表采用纯 SVG 矢量图与内联 Plotly 片段；
  4. 数据通过 JSON 载荷池完全内联打包，双击文件即可运行全部交互，现场拔掉网线验证分毫不差。
