## 一、 项目背景与问题需求

### 1. 现实背景与大语言模型在科学计算中的客观局限
大语言模型基于统计概率预测文本，在直接处理物理建模、航天轨道力学等严谨科学问题时，普遍存在以下工程难点：
1. **符号运算与量纲不确定性**：模型缺乏底层的物理公理闭环与单位量纲约束，直接口算物理量时容易出现量纲失配或非物理数值；
2. **缺乏多步工具调用与验证闭环**：单轮对话无法完成“问题解构 $\to$ 数据获取 $\to$ 控制方程确立 $\to$ 算法编写与积分 $\to$ 极端工况检验 $\to$ 异常回退 $\to$ 学术报告编排”的完整科研闭环；
3. **黑盒不可穿透、缺乏审计依据**：生成的数值结论缺乏透明的执行路径支撑，难以追溯到具体的参数输入、代码版本及执行回显；
4. **离线环境适应能力不足**：生成的报告若依赖外部在线 CDN，脱网环境下公式与排版易损坏；且跨机器部署时容易因缺少 Python 或科学计算包导致代码无法复现。

### 2. 项目目标与解决思路
本项目基于 **Agnes Harness（AGH）** 设计了 **AI 物理科研工作站（Physics Research Agent）**。核心设计思路是**“由大语言模型负责逻辑推理与程序编写，由外部确定性工具链负责数值计算与严格质检”**，通过引入符号量纲门禁、极端退化边界门禁、嵌入式便携运行时、出厂前 8 维报告质检与离线双栏时序热跳转，实现无人工干预条件下的物理研究辅助闭环，确保输出成果严谨、可验证、可审计。

## 二、 核心架构与方法论

### 1. 非侵入式“1 路由 + 9 专业子 Skill”解耦治理体系
- **设计初衷**：若将全部物理科研规范写入一份庞大的单体 Skill 文档，会导致长会话中提示词过长、模型容易产生规则注意力分散；若直接改动 AGH 平台源码，则破坏了底座的纯净性与可移植性。
- **具体实现方案**：
  严格遵循 **AGH 零侵入扩展原则（Zero-Intrusion Baseline）**，不修改宿主平台任何源代码。在 `.agh/skills/` 建立了 **10 个职责明确的标准原生工作区技能（1 个 `physics-agent-orchestrator` 原生路由中心 + 9 个专业子 Skill）**，由 AGH 宿主自动扫描加载，并在不同阶段按需激活：

**10 大原生工作区技能的具体分工**：
1. `physics-agent-orchestrator`：流程路由器，识别物理题型并动态激活 6 节点流水线；
2. `physics-agent-governance`：全局主控协议，统筹物理隔离原则（§5）、权限被拒即刻熔断铁律（§4）与双路径开门见山交付；
3. `physics-state-check`：任务隔离目录与 SSOT 状态账本（`problem_state.json`）生命周期管理；
4. `physics-pipeline`：第一性原理任务解构、费米估算、多轮渐进式探索（基线 ➔ 修正 ➔ 收敛）与权威数据源分层决策；
5. `physics-defense-lines`：SymPy 量纲齐次门禁、边界退化极限门禁与局部退火控制；
6. `physics-auditability`：原子化执行留痕、禁止单次覆盖历史、生成 `runlogs/*.txt` 真实运行资产；
7. `physics-report-charting`：科学绘图规范、外置胶囊图例条（曲线数据零遮挡）、公式自包含内联；
8. `physics-report-writing`：八章学术论证结构、七条行文规范（自适应“理论假设与适用局限”）；
9. `physics-permission-shortfall`：嵌入式便携运行时调度与权限/网络受限环境下的工程自愈；
10. `physics-doc-parsing`：外部文献数据手册与专业图纸按需结构化解析。

### 2. 测试规范：纯净环境与物理隔离原则（§5 隔离原则）
- **设计初衷**：在自动化评估与比赛评审时，若智能体工作区残留有历史研发笔记、中间调试记录或参考答案，模型可能会直接读取并复用答案，导致无法客观评估其真实的解题与工具调用能力。
- **具体实现方案**：
  设立独立的 `ability-test7` 纯净测试规范。在该规范下，在文件系统层面彻底物理剥离所有的研发辅助文档与历史记录（即完全移除 `dev-notes/` 目录）；智能体在一个全新的、空白的会话中启动，仅依托原生注册的 10 个 Skills 完成题干解析、数据获取、代码编写、门禁拦截与报告生成。
- **实际效果**：
  消除了工作区先验信息的干扰，确保测试过程完全基于模型自身的理解与工具调用，证明系统具备真实的解题泛化能力。

### 3. 环境保障：嵌入式便携运行时方案（Portable Runtime）
- **设计初衷**：实际评审或部署设备常常未安装 Python 3.10+ 环境，或缺少 NumPy、SciPy、SymPy、Pint 等重量级科学计算库，现场安装容易受网络波动与权限制约。
- **具体实现方案**：
  在 `physics-agent/third_party/portable-runtime/` 提供无安装器、不碰系统注册表的官方嵌入式 Python 3.13 运行环境，并预烘焙了版本锁定的依赖 wheels（`sympy==1.14.0`、`pint==0.26.1`、`numpy==2.5.3`、`scipy==1.18.1`、`matplotlib==3.11.2`、`plotly==7.1.0`）及 CJK 矢量字体。与 `physics-permission-shortfall` 技能协同，当环境检查发现系统缺少 Python 或必要依赖时，自动切换至便携运行时。
- **实际效果**：
  保证了在脱网、无全局 Python 或受限沙箱环境中，所有物理门禁与求解脚本均能开箱即用稳定运行。

## 三、 Agnes Harness 执行流程与六节点推进

1. **Node 0（状态检查与环境引导）**：初始化任务专属子目录 `physics-agent/runtime/<task-slug>/`，复制生成初始 `problem_state.json` 并记录当前 `session_key`；
2. **Node 1（任务理解与第一性解构）**：提取研究对象、外场相互作用，提炼一句话核心目标；支持复合多小问解构，理论推导题安全约束标为 N/A；先行执行**费米数量级估算**建立物理尺度感；
3. **Node 1.5（公开数据源路由）**：按四级分类决策树选用数据，公称基础物理常数优先直接调用标准库或教材定义，针对本地代理虚拟网卡（TUN 模式）拦截自动采用 Python 底层套接字直连穿透；
4. **Node 2a（机制匹配核验）**：对知识库方法模板进行逐行物理机制匹配检查，防范假设张冠李戴；无预制模板领域直接依据第一性物理定律与方法论知识库推演；
5. **Node 2b（建模求解与四重物理工程防线）**：现场编写独立 Python 求解模型，执行量纲齐次性检验、极限退化边界检验、多轮渐进迭代留痕（基线 ➔ 修正 ➔ 收敛），并与独立解析理论交叉对比；
6. **Node 3（增量学术报告合成）**：按八章学术标准增量汇总至 `<task-slug>/report.md`，执行七条行文规范（无内部黑话、无行内元导语、公式 LaTeX 排版、管道表格、提炼主导规律与失效边界）；
7. **Node 4（双栏离线排版与热交互引擎）**：由 `trace_visualizer.py` 编译产出单文件离线 HTML，内置 Section 9（质量审计与自愈返工复盘）、三轨会话甘特图、蓝链毫秒级热跳转（Hot Jump）与侧边栏自由拖拽缩放机制。

## 四、 三类运行工况与全链路验证证据链

为满足大赛对“正常情况、边界情况、失败情况”三类运行样例的严格验收要求，本项目以深空引力借力减速分析及历史真实走查记录提供全链路验证证据：

### 1. 正常工况（Normal Execution Case）
- **测试场景**：探测器以 $v_\infty = 20\ \text{km/s}$ 入射木星系，评估四颗伽利略卫星的单次飞掠最大减速量及推进剂节省比例；
- **执行过程与透明化调用**：
  - 智能体通过 Node 1 提炼核心目标，执行费米估算预判木卫一理论减速上限约 $24\ \text{km/s}$；
  - Node 1.5 路由至权威公开常数源（$G_J = 1.2669\times10^8\ \text{km}^3/\text{s}^2$、木卫一至木卫四轨道半长轴），透明记录于账本；
  - Node 2a 确认支配机制为无大气阻力影响的双体弹性动量交换，现场编写求解模型 `gravity_assist_model.py`；
  - Node 2b 成功求解：
    - 木卫一（Io）单次飞掠最大减速 $\Delta v_{probe} = 24.51\ \text{km/s}$，对 $15.59\ \text{km/s}$ 入轨需求覆盖率达 $157.2\%$；

### 2. 边界与极端工况（Boundary & Degenerate Limits Case）
- **测试场景**：验证模型在物理极端或退化条件下的数学自洽性与防发散能力；
- **边界探针设计（`boundary_spec.json`）**：
  1. **零引力退化极限**：令木星引力常数 $G_J \to 0$，卫星公转速度 $v_{moon} \to 0$。模型求解输出 $\Delta v_{probe} \to 0.0\ \text{km/s}$，自洽说明没有引力场时无法发生借力散射；
  2. **探测器质量无关性极限**：将卫星与探测器质量比放大 $10^6$ 倍。模型输出 $\Delta v_{probe} = 24.51\ \text{km/s}$ 严格保持恒定，符合双体弹性散射极限下减速量仅取决于卫星本底速度的物理结论；
  3. **渐近速度全域单调性扫描**：令入射速度在 $10 \sim 30\ \text{km/s}$ 范围内连续扫描，覆盖率单调平滑下降，无发散或非物理奇点。
- **核验结论**：边界门禁（`boundary_gate.py`）测试结果 100% PASS（3/3 探针全绿 + 扫描单调自洽），验证了模型在物理极值处的自洽性。

## 六、 双重质量防御门禁体系

为确保最终交付成果的规范性，项目在成果交付前执行双重自动化检查：

### 1. 出厂前 8 维质量门禁自动化检测（`report_quality_check.py`）
1. **Check 1（元导语拦截）**：过滤提示词诱导的行内自我说明，保证行文客观严肃；

3. **Check 3（Markdown 语法完整渲染）**：校验所有标题、引用块与表格是否均已转为语义化 HTML；
4. **Check 4（100% 离线 KaTeX 排版）**：校验公式是否本地内联编译，无外部在线 CDN 请求；
