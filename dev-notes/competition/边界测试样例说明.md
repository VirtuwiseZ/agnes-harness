## 一、 样例设计背景与边界测试必要性

根据大赛规程，“边界情况”要求展示：**输入处于特殊、极端或退化状态时，智能体能够主动识别情况并采取合理有效的处理验证，杜绝非物理发散与虚假收敛**。

### 1. 为什么纯大模型容易在边界条件下崩溃？
大语言模型通常在常见区间（如常温常压、常规行星速度）内具备良好的模式匹配能力，但在遇到物理极限（如质量趋向零、引力趋向零、距离趋向无穷大）时，往往会出现以下典型缺陷：
- **除以零崩溃（Zero-Division Singularity）**：控制方程中分母包含的参数趋向于零时，程序产生 `NaN` 或 `Inf`；
- **非物理恒定值输出**：模型凭感觉生造一个常数，违背极限物理守恒；
- **曲线振荡与突变**：在参数连续扫描时，出现不合常理的数值突变或非单调阶跃。

### 2. 边界测试的核心考察指标
在模型完成初版数值代码编写后，系统必须**主动构造一组不依赖经验常数的极端退化探针**，检验控制方程在数学极限下是否能自洽退化至经典物理公理。

## 二、 边界规范配置（`boundary_spec.json`）与四大极限探针设计

在流水线执行中，智能体自动为当前模型配置了形式化边界规范文件 `boundary_spec.json`，设计了三个物理极端退化探针与一个全域参数扫描探针：

```json
{
  "model_module": "gravity_assist_model",
  "primary_result": "delta_v_probe",
  "cases": [
    {
      "name": "zero_gravity_limit",
      "description": "当卫星引力常数趋近于零时，引力场消失，双曲散射偏折角趋于0，计算减速量必须严格为0",
      "overrides": {"G_jupiter": 1e-12},
      "expected_limit": 0.0,
      "tolerance": 1e-4
    },
    {
      "name": "large_distance_limit",
      "description": "当飞掠近心点距离远大于卫星引力作用球半径时，引力扰动消失，减速量必须趋近于0",
      "overrides": {"r_periapsis_factor": 1e6},
      "expected_limit": 0.0,
      "tolerance": 1e-4
    },
    {
      "name": "mass_invariance_limit",
      "description": "将探测器自身质量放大10^6倍，根据天体力学二体弹性散射定律，速度增量与探测器质量无关，计算结果必须严格保持不变",
      "overrides": {"probe_mass_kg": 1e6},
      "expected_limit": 0.5137,
      "tolerance": 1e-2
    }
  ],
  "monotonic_sweep": {
    "parameter": "v_inf",
    "range": [10.0, 40.0],
    "steps": 20,
    "expected_trend": "decreasing",
    "description": "当入射速度从10 km/s单调递增至40 km/s时，航天器飞掠有效作用时间缩短，引力减速量必须呈单调递减趋势，不得出现非物理波谷或震荡"
  }
}
```

### 探针物理判据与自洽性说明
1. **探针 1（零引力退化极限）**：
   - *理论依据*：当引力常数 $G \to 0$ 或卫星质量 $\mu_m \to 0$ 时，偏转角方程 $\sin(\delta/2) = \frac{1}{1 + r_p v_\infty^2 / \mu_m} \to 0$；
   - *自洽判据*：减速量 $\Delta v_{ga} \equiv 0.0\ \text{km/s}$，没有引力作用时不可能凭空产生减速。
2. **探针 2（超大飞掠距离极限）**：
   - *理论依据*：当飞掠距离 $r_p \to \infty$ 时，重力势能微扰趋近于零；
   - *自洽判据*：偏转角 $\delta \to 0$，减速量衰减为零，轨道保持未经扰动的直线双曲线。
3. **探针 3（探测器质量无关性极限）**：
   - *理论依据*：在限制性三体问题与开普勒轨道积分中，小天体（探测器）在引力场中的加速度仅取决于中心天体的质量与距离，与其自身质量无关；
   - *自洽判据*：探测器质量变化 $10^6$ 倍，木卫三飞掠减速值必须严格恒定为 $0.5137\ \text{km/s}$。
4. **探针 4（入射速度单调性全域扫描）**：
   - *理论依据*：来流初速 $v_\infty$ 越高，航天器掠过引力场的时间越短，引力积分冲量越小；
   - *自洽判据*：在 $10 \sim 40\ \text{km/s}$ 范围内连续采样 20 个离散点，减速量曲线必须处处满足 $\frac{d(\Delta v_{ga})}{d v_\infty} < 0$，证明求解算法无数值不稳定性。
