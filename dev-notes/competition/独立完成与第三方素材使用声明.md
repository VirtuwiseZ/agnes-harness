## 三、 大模型使用与调用合规声明（落实指南第六/七条要求）

根据《黑客松参赛指南》第六条与第七条规定，参赛队伍如实申报所用模型的名称、版本、使用环节与调用方式：

1. **模型名称与版本**：
   - **主选基线模型**：**Agnes-3.0-Flash**（赛事官方指定基线模型，由赛事组委会统一分配调用凭据）；
   - **对照与鲁棒性验证基准**：**Gemini-3.8-Flash**、**Claude-Opus-4.6-Thinking**（用于跨模型推理验证与对比测试）。
2. **模型具体使用环节**：
   - **Node 1（第一性任务解构）**：概念拆解、研究对象与相互作用识别、提炼一句话核心研究目标；
   - **Node 2a（机制核验）**：核对物理模型假设是否与当前命题场景匹配，防范模型错误套用不相关的公式模板；
   - **Node 2b（建模求解）**：编写求解微分方程的 Python 代码与边界自检测试脚本；
   - **Node 3（报告撰写）**：按照学术规范组织八章内容，提炼主导物理规律与失效边界。
3. **调用机制与反口算约束**：
   - **不使用模型口算物理量**：所有模型均运行在 AGH 的调度环路中，仅负责推理概念与生成代码，物理数值积分、量纲验证与方程验算全部由外部独立 Python 解释器执行；
   - **全过程留痕可核查**：所有模型调用、Prompt 交互与工具回显均由 AGH 自动记录于只读 `trace.jsonl` 账本中，带有毫秒级时间戳与 SHA-256 散列签名，无法事后人工篡改。

## 四、 第三方数据源参考名录与接入体系声明

为保证物理科研智能体在解决不同物理细分领域命题时具备**权威、标准、可复现的数据支撑**，本项目在系统设计中建立了规范化的**第三方权威数据源参考名录与准入体系**。

**说明**：本名录体系是系统面向不同物理细分领域预先梳理的公开数据检索与处理参考目录，为智能体提供合规的数据检索引导，并非针对某一特定题目量身预制，亦非封闭的穷举白名单。

### 1. AI 自主处理数据源的准入准则
为确保模型能够自动获取并处理外部数据，纳入本名录体系的数据源遵循以下工程准则：
1. **公开且免认证/免登录**：支持标准 HTTP GET 请求，不设账号登录、验证码或私有网络限制；
2. **结构化良好**：提供标准 RESTful API、JSON、CSV、TSV 等格式，或采用规范的 HTML 数据表格组织；
3. **权威性与标准化**：数据源自公认的科研机构与国际标准化组织（如 NASA、NIST、CODATA、IAU、ISO 等），具有广泛的学术公信力；
4. **易于代码集成**：在 Python 生态中具备成熟的解析库或标准处理工具，便于编写脚本进行清洗与提取。

### 2. 建立的第三方权威数据源名录（按物理细分领域组织）

本项目在系统知识库（`physics-agent/knowledge/data_source_catalog.md` 及相关数据规范）中为智能体梳理了覆盖天体、大气、热力学、基础常数等多物理领域的权威第三方数据源名录：

- **天文学、系外行星与天体轨道动力学（Celestial & Orbital Mechanics）**：
  - **NASA JPL Horizons API**：提供太阳系行星、小行星及彗星的开普勒轨道根数与瞬时三维高精度星历状态矢量（Ephemeris）；
  - **NASA JPL Small-Body Database (SBDB) API**：提供近地天体（NEO）与小行星的物理特征参数（质量、直径、反照率、自转周期等）；
  - **NASA NSSDC Planetary Fact Sheets**：汇总各大行星及其主要卫星的标准引力常数、质量、轨道半径、逃逸速度等公认物理基准；
  - **NASA Exoplanet Archive (JPL-Caltech `pscomppars`)**：国际系外行星质量-半径及恒星系统参数标准观测数据库；
  - **Python 天体物理与轨道计算库**：`astropy` / `astroquery`（IVOA 标准天文服务查询）、`poliastro` 等天体力学工具生态。
- **空气动力学、大气物理与气象环境（Aerodynamics, Atmosphere & Meteorology）**：
  - **标准大气物理模型（US Standard Atmosphere 1976 / ISA）**：提供从海平面到高空的温度、气压、空气密度与声速剖面（结合 `ambiance` 库及 NASA CCMC NRLMSIS-00 `pymsis` 模型）；
  - **流体阻力与空气动力学工程数据库（Engineering ToolBox）**：提供不同雷诺数下的阻力系数 $C_d$、Sutherland 粘度公式、热导率及气体物性曲线；
  - **NASA Glenn Research Center 气动物理参考库**：提供升阻力经验模型、旋转体马格努斯效应及推进气动参数；
  - **NASA GISS GISTEMP / NASA POWER**：全球长期地表气温距平数据集与气象再分析网格数据；
  - **Open-Meteo API**：开放气象与大气监测接口。
- **热力学、统计物理与材料物性（Thermodynamics & Materials）**：
  - **NIST Chemistry WebBook (美国国家标准与技术研究院化学数据库)**：常见流体与气体的状态方程（EOS）、相变潜热、饱和蒸汽压曲线（Antoine 方程参数）以及定压比热容随温度的多项式系数（Shomate 方程）；
  - **SwRI Phidrates 数据库**：行星大气分子在太阳辐射下的光化学解离速率与截面数据库；
  - **WDC-SILSO（比利时皇家天文台）**：国际太阳黑子活动指数长期月均数据集。
- **基础物理常数、原子光谱与计量学（Fundamental Constants & Spectroscopy）**：
  - **NIST / CODATA 基础物理常数数据库**：提供最新 CODATA 国际推荐基础物理常数（通过 `scipy.constants` 标准内置集成），涵盖万有引力常数 $G$、真空光速 $c$、普朗克常数 $h$、玻尔兹曼常数 $k_B$ 等；
  - **NIST Atomic Spectra Database (ASD)**：国际公认的原子与离子特征发射光谱线、跃迁几率与能级基准；
  - **MolSSI / QCElemental**：量子化学与元素周期物理常数解析库。
- **流体力学与数值模拟框架（Fluid Dynamics）**：
  - **`fluiddyn/fluidsim`**：流体力学数值模拟框架候选，支持二维/三维连续流场求解。
- **学术预印本与开放科学知识库（Scientific Literature & Fact Bases）**：
  - **arXiv API**：天体物理、经典力学与流动动力学领域的学术预印本检索接口；
  - **NASA Technical Reports Server (NTRS) API**：NASA 历史上公开的技术备忘录、工程报告与实验测定数据；
  - **OpenAlex 学术数据库**：开放学术文献元数据与 DOI 关联索引；
  - **MediaWiki REST API**：开放知识百科中的工程标准规格与公认历史物理参数提取。

### 3. 数据源决策树（Level 0~3）与自主检索机制
在实际执行中，智能体执行四级数据源路由决策：
- **Level 0（本地权威库优先）**：优先使用标准科学计算库（如 `scipy.constants`）或本地已配置的标准物理量纲库；
- **Level 1（官方免密 REST API）**：优先调用免密、官方可信的 REST API，通过自动化脚本在线获取；
- **Level 2（权威静态备份数据）**：使用预置或本地缓存的经核对官方数据源；
- **Level 3（人机协同请求）**：仅在外部数据必须人工授权或涉及私有权限时向用户发出明确请求。

**非穷举免责声明**：本名录体系作为智能体的引导参考，未穷尽所有物理学分支领域。当命题涉及名录未覆盖的特殊物理分支时，系统允许并支持智能体在遵守防幻觉纪律的前提下，自主检索合规的公开发表数据并完成跨源交叉校验，确保科学研究的开放性与严谨性。
