## 二、 独立完成确认承诺

根据《2026年江苏省AI+科学与工程创新实践黑客松参赛指南》第十三条及相关学术诚信规定，参赛团队全体成员郑重作出如下承诺与确认：

1. **作品原创性确认**：本项目《AI物理科研工作站（Physics Research Agent）——基于 Agnes Harness 的确定性物理科研智能体》由参赛团队全体成员在赛事期间**独立构思、架构设计、算法实现、代码编写、系统调试与验证完成**；
2. **指导教师指导边界说明**：本团队严格恪守大赛指导边界规范，高校指导教师仅提供宏观科学原理咨询、选题方向论证与学术规范指导，**未直接代写项目核心代码、未代做关键算法实现、未代行系统联调**；
3. **学术诚信与防代赛承诺**：本项目不存在高校教师代做、校外商业机构代赛代包、买卖代码、抄袭剽窃他人既有项目成果或冒用未授权第三方资产等行为；
4. **自主研发核心组件清单**：以下核心机制与工程组件均由本团队自主设计并独立编程实现：
   - 遵循 AGH 零侵入原则的 **10 个标准原生工作区技能**（1 个原生路由器 + 9 个专业子 Skill）；
   - **§5 物理隔离原则纯净测试规范**（文件系统级物理剥离开发草稿与历史参考答案，实现冷启动泛化解题）；
   - **确定性物理防御门禁系统**（`dimensional_gate.py`、`boundary_gate.py`、`audit_log.py`）；
   - **出厂前双重质量防御工具**（8 维质量门禁 `report_quality_check.py` 与技能 BOM 门禁 `skill_bom_check.py`）；
   - **100% 离线自包含双栏交互报告引擎**（`trace_visualizer.py`，实现外置 Flex 胶囊图例条零遮挡、三轨会话甘特图内联、蓝链毫秒级热跳转与侧边栏自由拖拽拉伸）；
   - **嵌入式便携运行时方案**（基于 Python 3.13 embed 的即插即用科学计算环境与 wheels 离线配置）；
5. **法律与诚信责任**：全体参赛学生对提交作品的技术真实性、数据严谨性、测试记录的客观性及申报材料的真实完整承担全部诚信与学术责任。

## 四、 第三方权威公开数据源使用声明

本项目严格遵循学术规范，所涉及的天文轨道常数与基础物理公称常数均来自国际公认的科研机构与官方标准组织发布的公开数据集，不涉及任何商业机密、专有数据或未经授权的数据资产：

1. **NASA JPL Horizons 星历系统公开常数库**：
   - 引用内容：木星标准引力常数 $G_J = 1.2669\times 10^8\ \text{km}^3/\text{s}^2$、木卫一至木卫四轨道半长轴、公转周期与偏心率；
   - 使用方式：在 Node 1.5 中作为任务基准参数记录于状态账本，为后续轨道动力学仿真提供基准常数。
2. **国际天文学联合会（IAU 2015）推荐天文学常数系统**：
   - 引用内容：大行星与主卫星质量比、平均轨道倾角与物理半径常数；
   - 使用方式：用于边界极限测试中极端质量比的标定与理论校验。
3. **国际科技数据委员会（CODATA 2022）推荐基础物理常数**：
   - 引用内容：万有引力常数 $G$、真空光速 $c$、普朗克常数 $h$；
   - 使用方式：内置于基础科学常数表中，供光学推导与引力建模调用。
4. **标准大学物理教学公称参数**：
   - 引用内容：可见光中心波长（红光 650 nm、绿光 550 nm、蓝光 450 nm）、人眼明视觉瞳孔公称孔径（3 mm）；
   - 使用方式：用于大学物理单缝衍射图样生成及长城肉眼辨识假说定量论证。
