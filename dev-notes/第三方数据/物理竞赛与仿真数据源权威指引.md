# 物理竞赛与仿真数据源权威指引 (Physics Simulation Data Sources Guide)

> **定位与职责**：本项目在大学生物理竞赛（UPC）、科研建模与工程仿真中**获取外部客观参数与基准数据**的唯一权威操作指南。
> **适用节点**：由 `.agh/skills/physics-pipeline/SKILL.md` 的 **Node 1.5（数据源路由与获取）** 直接指向并强制执行。
> **编制依据**：结合 2010–2025 年历届金牌论文数据源分析、开发者实际诉求，以及 2026-10-13 在真实网络环境下对全球主流科学数据库的**实测连通性结果**。

## 第一部分：三大可接入性等级划分（三档整理与简要标签）

根据 AI Agent 在运行环境中能否直接通过代码或网络工具获取，将所有数据源严格划分为以下三档：

### 🟢 第一档：确认可直接拉取（AI 自主闭环，免认证、结构化接口、实测 100% 连通）

这类数据源支持标准的 HTTP GET 请求，返回规整的 JSON、CSV、XML 或标准化 HTML 表格，或者直接内置在 Python 离线科学计算包中，AI 可**自主编写脚本直接获取并清洗**：

| 数据源名称 | 机构 / 组织 | 核心数据类型 | 简要标签 | 实测状态与接入方式 |
|---|---|---|---|---|
| **NASA JPL SBDB API** | NASA 喷气推进实验室 | 小行星/近地天体轨道根数、物理参数、非引力加速度 | `[天文动力学]` `[近地天体]` `[REST API]` | **HTTP 200** 实测可用：`https://ssd-api.jpl.nasa.gov/sbdb.api?sstr=小行星名` 直接返回 JSON。 |
| **NASA Planetary Fact Sheets** | NASA 戈达德太空飞行中心 (GSFC) | 太阳系行星与卫星质量、半径、表面重力、轨道半长轴等 | `[天体物理]` `[行星常数]` `[结构化表格]` | **HTTP 200** 实测可用：`https://nssdc.gsfc.nasa.gov/planetary/factsheet/`，支持 `pandas.read_html` 一键解析。 |
| **NIST Chemistry WebBook** | 美国国家标准与技术研究院 (NIST) | 气体状态方程、相变焓、Antoine蒸气压、Shomate比热容多项式 | `[热力学]` `[物性拟合]` `[权威基准]` | **HTTP 200** 实测可用：`https://webbook.nist.gov/cgi/cbook.cgi?ID=CAS号&Units=SI&Mask=1` 直接提取 Shomate 系数。 |

| **NOAA SWPC API** | 美国国家海洋与大气管理局 (NOAA) | 地球磁场指数 (Kp)、太阳风通量、太阳黑子数、电离层扰动 | `[空间天气]` `[地磁监测]` `[实时数据]` | **HTTP 200** 实测可用：`https://services.swpc.noaa.gov/json/planetary_k_index_1m.json` 返回高频实测时间序列。 |
| **OpenAlex API** | OurResearch 开放科学组织 | 全球开放获取物理学论文元数据、开放全文链接、引用关系 | `[前沿文献]` `[开放获取]` `[REST API]` | **HTTP 200** 实测可用：`https://api.openalex.org/works?search=...` 免 API Key 直接检索论文摘要与参数。 |
| **arXiv API (HTTPS)** | 康奈尔大学预印本库 (arXiv) | 天体物理、经典力学、流体动力学等最新开放物理预印本全文 | `[预印本库]` `[理论建模]` `[REST API]` | **HTTP 200** 实测可用：`https://export.arxiv.org/api/query?search_query=...`（注意：必须使用 HTTPS，HTTP 会被拦截）。 |
| **Python 核心离线科学库** | SciPy / Astropy / Ambiance / Pint | CODATA 2022 基础物理常数、标准大气 1976 模型、天体质量参数 | `[本地离线]` `[零网络依赖]` `[微秒响应]` | **100% 绝对可用**：`scipy.constants`、`astropy.constants`、`ambiance` 无需任何外部网络，代码内直接 `import`。 |
| **本地预烘焙公开基准集** | 本项目 `dev-notes/第三方数据/` | GISTEMP 全球温度异常、SIDC 太阳黑子、系外行星质量半径、NIST 常数表 | `[项目内置]` `[金牌基准]` `[离线CSV]` | **100% 绝对可用**：直接在代码中通过相对路径读取，作为独立验证基准。 |

### 🔴 第二档：确认无法绕过账号/API/付费等限制（需参赛队员人工查找并整理交付）

这类数据源由于**商业版权收费、校园网 IP 绑定、强风控反爬滑块验证或人工审批流程**，AI 自动化代码绝对无法自主获取，必须由队员在比赛期间通过合法渠道查阅、提取后，以标准格式交付给 AI：

| 数据源名称 | 机构 / 平台 | 无法直连原因剖析 | 简要标签 | 人工整理与交付要点 |
|---|---|---|---|---|
| **中国知网 (CNKI) / 万方数据** | 中国知网、万方 | 严格限制高校校园网 IP / CARSI 身份认证，对自动化抓取有高强度 IP 封禁策略。 | `[中文期刊]` `[硕博论文]` `[校园网限制]` | 队员通过学校 VPN 检索下载论文 PDF，提取论文中作者拟合的微分方程系数（如弹道阻力、风场阻尼），以文本/键值对喂给 AI。 |
| **AIAA / IEEE Xplore / ScienceDirect** | 各国际专业学术商业出版商 | 单篇需高昂付费（30~45 美元/篇），受跨国机构订阅与反爬网关严格限制。 | `[国际顶刊]` `[航天/电子]` `[商业付费墙]` | 队员查阅下载论文，直接摘抄图表中的核心参数（如超音速球体阻力系数随马赫数变化），换算为国际单位制后传递给 AI。 |
| **电商平台实物规格 (京东/淘宝/Amazon)** | 主流商业电商平台 | 部署有极其严格的设备指纹检测、滑动拼图验证码及强制登录拦截。 | `[工业实物]` `[工程参数]` `[强反爬风控]` | 在涉及生活/体育工程题时（如蹦床弹簧、无人机电机），队员直接搜索商品详情页，核对线径、圈数、功率，计算出等效劲度系数 $k$ 后喂给 AI。 |
| **中国国家航天局 (CNSA) 月球与深空探测科学数据网** | 中国国家航天局探月与航天工程中心 (`moon.bao.ac.cn`) | 实测连通超时；官方要求实名账号注册申请，数据发布需经过人工审核审批。 | `[中国航天]` `[探月工程]` `[人工审批]` | 若题目涉及嫦娥/天问任务探测数据，需队员提前在官方门户申请脱敏公开数据集并下载为本地文件。 |
| **多媒体与非结构化实验视频** | Bilibili / YouTube / 体育赛事转播 | 视频格式属于高维度非结构化像素流，无现成数值表格。 | `[实验视频]` `[运动反演]` `[非结构化]` | 队员利用 Tracker 视频运动分析软件进行逐帧打点，导出“时间-位移”散点 CSV 文件交给 AI 导入拟合。 |
| **行业协会与体育组织官方技术手册** | FIBA / ITTF / FIG / 军工手册 | 以数十页乃至上百页复杂排版的大型 PDF 存在，扫描件公式识别难度极高。 | `[行业标准]` `[器材规格]` `[复杂PDF]` | 队员翻查至“器材规范（Equipment Specifications）”章节，提取标准尺寸、公差与弹性恢复系数。 |

## 第二部分：按物理领域分类的详细数据源名录与代码接入模板

### 1. 天体物理与星际轨道动力学 (Astrophysics & Orbital Mechanics)
- **NASA JPL Horizons API**：
  - *URL*: `https://ssd-api.jpl.nasa.gov/horizons.api`
  - *适用场景*: 太阳系星体瞬态相对位置、开普勒六根数、引力助推计算、拉格朗日点定位。
  - *Python 调用范例*:
    ```python
    import requests
    # 查询火星相对太阳的即时开普勒根数
    params = {
        "format": "json", "COMMAND": "'499'", "OBJ_DATA": "YES",
        "MAKE_EPHEM": "YES", "EPHEM_TYPE": "ELEMENTS", "CENTER": "'@sun'"
    }
    r = requests.get("https://ssd-api.jpl.nasa.gov/horizons.api", params=params, timeout=10)
    data = r.json()
    ```
- **NASA JPL Small-Body Database (SBDB)**：
  - *URL*: `https://ssd-api.jpl.nasa.gov/sbdb.api?sstr=小行星编号`
  - *适用场景*: 小行星撞击防御、轨道偏转、近地天体偏心率与反照率。
- **NASA NSSDC Planetary Fact Sheets**：
  - *URL*: `https://nssdc.gsfc.nasa.gov/planetary/factsheet/`
  - *适用场景*: 行星与天然卫星标准常数表（质量 $M$、赤道半径 $R$、引力参数 $GM$、自转周期）。

### 2. 空气动力学与流体/高空大气 (Aerodynamics & Atmosphere)
- **US Standard Atmosphere 1976 (`ambiance` 库，第一档)**：
  - *适用场景*: 0–86 km 范围内的对流层/平流层连续温度 $T(z)$、气压 $P(z)$、密度 $\rho(z)$、声速 $a(z)$。
  - *代码调用范例*:
    ```python
    from ambiance import Atmosphere
    atm = Atmosphere(10000.0) # 10 km 高度
    print(atm.density[0], atm.speed_of_sound[0], atm.temperature[0])
    ```
- **NRLMSIS-00 / 2.1 高空大气模型 (`pymsis` 库，第一档)**：
  - *适用场景*: 86–1000 km 极高空变温变密度热层与外大气层，用于航天器再入与极限太空跳伞。

### 3. 热力学、相变与材料物性 (Thermodynamics & Materials)
- **NIST Chemistry WebBook (第一档)**：
  - *URL*: `https://webbook.nist.gov/chemistry/`
  - *适用场景*: $\text{CO}_2$、水蒸气、甲烷等气体的 Shomate 拟合比热容公式、相变焓。
- **CODATA 基础物理常数 (`scipy.constants`，第一档)**：
  - *适用场景*: 引力常数 $G$、玻尔兹曼常数 $k_B$、光速 $c$、普朗克常数 $h$。
    ```python
    from scipy.constants import G, k, c, h, N_A
    ```
- **PubChem PUG REST API (第一档)**：
  - *URL*: `https://pubchem.ncbi.nlm.nih.gov/rest/pug/`
  - *适用场景*: 化合物相对分子质量、标准密度、热力学物性一键查询。

### 4. 地球物理、空间天气与太阳活动 (Geophysics & Space Weather)
- **NOAA 空间天气预测中心 API (第一档)**：
  - *URL*: `https://services.swpc.noaa.gov/json/planetary_k_index_1m.json`
  - *适用场景*: 太阳风暴对近地轨道卫星电离层阻力的扰动、地磁 Kp 指数。
- **SIDC 太阳黑子长期序列 (`dev-notes/第三方数据/sidc_sunspot_monthly_1749-2026.csv`，第一档)**：
  - *适用场景*: 太阳 11 年活动周期与长周期辐射通量演化。

### 5. 学术文献、前沿模型与公开科学平台
- **OpenAlex 学术文献元数据 API (第一档)**：
  - *URL*: `https://api.openalex.org/`
  - *适用场景*: 检索经典论文发表年份、核心结论参数、寻找同类物理模型参考文献。
- **arXiv 预印本 API (第一档)**：
  - *URL*: `https://export.arxiv.org/api/query`
  - *适用场景*: 检索前沿天体物理与经典力学开放论文全文链接。
- **中国科学院科学数据银行 (ScienceDB, 第三档)**：
  - *URL*: `https://www.sciencedb.cn/`
  - *适用场景*: 寻找中国科学家开源的大气、海洋、地理综合实测数据集。

## 第三部分：Skill 联动规则与标准操作流程 (SOP)

为使本指引在真实解题中得到自动化落实，在 `.agh/skills/physics-pipeline/SKILL.md` 的 **Node 1.5** 阶段必须强制执行以下**数据源决策 SOP**：

```
[Node 1.5 数据源路由 SOP]
  1. 首先判断所需数据属于哪个物理大类；
  2. 优先检查「第一档」中是否有现成的本地 Python 库 (Level 0) 或本地 CSV 数据集 (Level 2)；
     → 若有，直接在代码中 import，零网络开销，最可靠；
  3. 若必须从外部拉取，查阅「第一档」的官方公开 REST API：
     → 检查当前网络连通性（参考 notes-for-ai/network_and_vpn_guidelines.md）；
     → 发起 HTTP 请求，获得数据后记录审计日志；
  4. 若所需数据属于「第二档」（商业学术论文、电商实物参数、复杂视频打点）：
     → 立即触发人机协作流程（Fault-tolerance Option A）：向用户清晰说明所需物理量的名称与推荐渠道，
       等待用户人工查阅后回传数值；
  5. 严禁凭空捏造未经验证的真实物理观测数据，严禁在缺乏数据时静默跳过验证！
```
