> **定位与职责**：本项目在大学生物理竞赛（UPC）、科研建模与工程仿真中**获取外部客观参数、实测时间序列与独立验证基准**的唯一权威操作指南。
> **适用节点**：由 `.agh/skills/physics-pipeline/SKILL.md` 的 **Node 1.5（数据源路由与获取）** 以及路由器插件 `physics-agent-orchestrator` 直接调度并强制执行。
> **跨文档协同（架构互指）**：
> - 联网异常与代理诊断：严格参照 [`network_and_vpn_guidelines.md`](../../physics-agent/knowledge/network_and_vpn_guidelines.md) 或 [`dev-notes/notes-for-ai/network_and_vpn_guidelines.md`](../notes-for-ai/network_and_vpn_guidelines.md)；
> - 运行规范与数据闭环：严格对照 `.agh/skills/physics-pipeline/SKILL.md` 的 Node 1.5 数据源路由 SOP；
> - 离线数据存储：优先使用 `physics-agent/knowledge/reference_data/` 目录内的预置基准文件。

## 前置铁律：第一档数据源的生效网络前提与连通性准则

在尝试调用外部网络获取数据前，AI Agent 必须根据当前运行环境确定网络模式，**严禁在错误的网络模式下盲目报错或放弃**：

| 网络状态场景 | 目标数据源类型 | `web_fetch` 预期行为 | 推荐接入通道与解决方案（快速互指） |
|---|---|---|---|
| **场景 A：开启 VPN + 标准系统代理模式** | 国际权威 API (NASA, NIST, OpenAlex, arXiv 等) | ✅ **HTTP 200 成功**（实测验证） | 直接使用宿主工具 `web_fetch`，毫秒级获取 JSON/HTML/XML。 |
| **场景 B：开启 VPN + 虚拟网卡 (TUN) / Fake-IP 模式** | 国际权威 API (NASA, NIST, OpenAlex, arXiv 等) | ❌ **抛出 `resolves to a non-public IP` 拦截** | **严禁放弃！** 改用 Python 单行/短脚本通过系统底层 Socket 网络栈直连（详见 `network_and_vpn_guidelines.md` 方案 1），流量经 TUN 网卡正常出境。 |
| **场景 C：国内普通网络 + 大陆直连模型（无 VPN）** | 境外数据源 (NASA 等) | ⚠ 可能超时或 DNS 阻断（待专项实测） | **自动降级至国内开放源或 Level 0 离线科学库**：切换至 ScienceDB / NADC / CMA 或调用 `scipy.constants`。 |
| **场景 D：完全无网 / 离线沙箱环境** | 全部数据源 | ❌ 网络不可达 | **触发 Level 0 / Level 2 保底机制**：使用 `scipy.constants`、`astropy.constants`、`ambiance` 及 `reference_data/*.csv`，100% 离线自包含可用。 |

## 第一部分：三大可接入性等级划分（三档整理与简要标签）

根据 AI Agent 在运行环境中能否直接通过代码或网络工具获取，将历届金牌论文、历次自测以及公共科学数据源严格划分为以下三档：

### 🟢 第一档：确认可直接拉取（AI 自主闭环，免认证、免登录、结构化接口/离线库）

这类数据源支持标准的 HTTP GET 请求，返回规整的 JSON、CSV、XML 或标准化 HTML 表格，或者直接内置在 Python 离线科学计算包中，AI 可**自主编写脚本直接获取并清洗**（在场景 A 或场景 B 下 100% 成功）：

| 数据源名称 | 机构 / 组织 | 核心数据类型 | 简要标签 | 实测状态与调用方式 |
|---|---|---|---|---|
| **NASA JPL SBDB API** | NASA 喷气推进实验室 | 小行星/近地天体轨道根数、物理参数、非引力加速度 | `[天文动力学]` `[近地天体]` `[REST API]` | **HTTP 200** 实测可用：`https://ssd-api.jpl.nasa.gov/sbdb.api?sstr=小行星名` 直接返回 JSON。 |

| **NASA JPL Horizons API** | NASA 喷气推进实验室 | 太阳系行星与深空探测器精密星历（瞬态位置与速度三维矢量） | `[星际轨道]` `[精密星历]` `[REST API]` | **HTTP 200** 可用：`https://ssd-api.jpl.nasa.gov/horizons.api`，支持直接参数构造或 `astroquery`。 |

| **国家天文科学数据中心 (NADC)** | 中国科学院国家天文台 | LAMOST 恒星光谱、天文测量基准、巡天星表 | `[国家天文]` `[恒星光谱]` `[需评估认证]` | **猜测原因**：公开星表通常支持 TAP (Table Access Protocol) 检索，但部分精细释放数据包需要 NADC 注册账号或批量 FTP 客户端，AI 单次请求易受限。 |

## 第二部分：按物理领域与数据类型分类的详细名录与接入/处理方案

### 1. 天体物理与星际轨道动力学 (Astrophysics & Orbital Mechanics)
- **NASA JPL Horizons API (第一档)**：
  - *URL*: `https://ssd-api.jpl.nasa.gov/horizons.api`
  - *适用场景*: 太阳系星体瞬态相对位置、开普勒六根数、引力助推计算、拉格朗日点定位。
- **NASA JPL Small-Body Database (SBDB) (第一档)**：
  - *URL*: `https://ssd-api.jpl.nasa.gov/sbdb.api?sstr=小行星编号`
  - *适用场景*: 小行星撞击防御、轨道偏转、近地天体偏心率与反照率（如阿波菲斯 Apophis、贝努 Bennu）。
- **NASA NSSDC Planetary Fact Sheets (第一档)**：
  - *URL*: `https://nssdc.gsfc.nasa.gov/planetary/factsheet/`
  - *适用场景*: 行星与天然卫星标准常数表（质量 $M$、赤道半径 $R$、引力参数 $GM$、自转周期）。
- **国家天文科学数据中心 NADC (第三档)**：
  - *URL*: `https://nadc.china-vo.org/`
  - *适用场景*: 国内大视场巡天（LAMOST、FAST）恒星与射电参数，需人工注册辅助。

### 2. 空气动力学、高空大气与弹道流体 (Aerodynamics, Atmosphere & Ballistics)
- **US Standard Atmosphere 1976 (`ambiance` 库，第一档，Level 0)**：
  - *适用场景*: 0–86 km 范围内的对流层/平流层连续温度 $T(z)$、气压 $P(z)$、密度 $\rho(z)$、声速 $a(z)$。
- **NRLMSIS-00 / 2.1 高空大气模型 (`pymsis` 库，第一档，Level 0)**：
  - *适用场景*: 86–1000 km 极高空变温变密度热层与外大气层，用于航天器再入与极限太空跳伞。
- **韩子鹏《弹箭外弹道学》/ McCoy 外弹道专著 (第二档)**：
  - *适用场景*: 旋转弹丸马格努斯力、不同马赫数超音速阻力系数拟合曲线，由参赛队员查阅提供。
- **国家气象科学数据中心 CMA (第三档)**：
  - *URL*: `https://data.cma.cn/`
  - *适用场景*: 国内各高度层探空气球真实风场与温湿压时序。

### 3. 热力学、相变与材料物性 (Thermodynamics & Materials)
- **NIST Chemistry WebBook (第一档)**：
  - *URL*: `https://webbook.nist.gov/chemistry/`
  - *适用场景*: $\text{CO}_2$、水蒸气、甲烷等气体的 Shomate 拟合比热容公式、相变焓。
- **PubChem PUG REST API (第一档)**：
  - *URL*: `https://pubchem.ncbi.nlm.nih.gov/rest/pug/`
  - *适用场景*: 各种化合物分子量、密度、沸点等物理化学参数。
- **CODATA 基础物理常数 (`scipy.constants`，第一档，Level 0)**：
  - *适用场景*: 引力常数 $G$、玻尔兹曼常数 $k_B$、光速 $c$、普朗克常数 $h$。
- **MatWeb / Materials Project (第二档 / 第三档)**：
  - *适用场景*: 特种合金屈服强度、石墨烯抗拉极限，优先由队员人工检索或传入 API Key。

### 4. 地球物理、空间天气、气候与空间热图网格 (Geophysics, Climate & Spatial Grids)
- **NOAA 空间天气预测中心 API (第一档)**：
  - *URL*: `https://services.swpc.noaa.gov/json/planetary_k_index_1m.json`

### 执行铁律
1. **真实数据绝不凭空捏造**：严禁在缺乏真实数据时伪造虚假常数或假设。
2. **人机协作有条不紊**：遇到第二档数据时，AI 必须向用户明确说明：“当前参数属于第二档受限数据源（如知网/电商/视频），请协助在 [推荐渠道] 查阅并提供 [参数名称/单位]，我将立即代入模型”。
3. **网络异常秒级自适应**：一旦遇到网络拦截，立即翻阅 `network_and_vpn_guidelines.md`，执行 Python OS 网络栈直连或离线库保底，绝不陷入死循环。
