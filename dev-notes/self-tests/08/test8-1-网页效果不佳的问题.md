## 一、 问题现象与初始诊断回顾

在 Test 8 测试中，用户在开启全部 10 个 Skills 与插件的全新环境中输入了火炮外弹道赛题，但最终生成的 HTML 网页报告（`research_report_historical-artillery-ballistics.html`）质量远低于预期，表现为“神形皆散”、缺乏真实感与工程深度，不如之前未开 Skills 时自己做得好。

通过逐行审查 `events.jsonl`，查明了导致该现象的**根本原因链条**：

### 1. 致命断链：`shell` 工具调用遭遇 Schema 拦截，外部 Python 计算全线瘫痪
- 从第 14 步开始（Seq 269 到 Seq 403），模型尝试调用 `shell` 验证 Python 环境与运行门禁，但传入的参数被客户端/代理层错误包裹为嵌套 JSON：
  ```json
  {"name": "shell", "args": {"input": "{\"command\":\"python --version\"}"}}
  ```
- AGH 宿主基于严格的 TypeBox Schema 校验，直接报错拦截：
  ```text
  tool arguments do not match the registered schema: /command: missing required parameter.
  ```
- **模型连续尝试了 8 次 `shell` 调用，全部被判 `TOOL_ARGS_INVALID`**！
- 在 Seq 609，模型在思维链中认定：“执行工具出现参数序列化错误，我无法运行任何子进程，只能靠在内存中进行状态推演和估算”。

### 2. 多米诺骨牌级溃败：确定性工程底座被强行架空
由于 `shell` 彻底不可用，直接引发了连锁工程失效：
1. **真实数值求解从未发生**：模型虽在 Seq 894 写入了 `ballistics_model.py`，但**该脚本从未被 Python 实际执行**！四阶龙格-库塔数值积分、1000~1500 米射程扫描表及风偏灵敏度全部是模型在思维链中“心算估计”的数值；
2. **两道核心物理门禁被完全跳过**：`dimensional_gate.py` 与 `boundary_gate.py` 一次都没跑过，缺乏形式化数学与物理退化极限的客观机器背书；
3. **图表生成器被跳过**：`make_report_figures.py` 未能运行，无法生成数据驱动的真实矢量图表；
4. **核心排版引擎被跳过**：Node 4 的 `trace_visualizer.py` 根本无法调用。

### 3. 被迫无奈的“打肿脸充胖子”：模型徒手“手搓”了 36KB 的仿制 HTML
- 在 Seq 935，模型为了完成交付，**直接调用 `write` 工具在单次回复中徒手写了一个 36,336 字节的 HTML 文件**；
- 这个手搓 HTML 虽然模仿了部分样式，但存在致命缺陷：
  - **图表是模型手画的简易二次贝塞尔曲线**，缺乏真实气动力学与龙格-库塔积分轨迹；
  - **缺乏真实的会话时序记录与三轨甘特图**；
  - **点击正文蓝链没有任何反应**（完全缺失 `trace_visualizer.py` 注入的 `highlightTraceSeq` 毫秒级热跳转数据池与发光动画）；
  - **没有通过出厂前 8 维质量门禁审查**（`report_quality_check.py`）；
  - **缺乏第 9 节真正的不可篡改审计体系与四大自愈复盘**。
