1. 摘要

针对以 v∞ = 20 km/s 超高双曲过剩速度抵近木星系统的深空探测器，本文基于第一性原理天体动力学、拼接圆锥曲线（Patched Conics）双体散射理论及奥伯斯特效应（Oberth Effect），系统评估了利用木星四颗伽利略卫星（木卫一 Io、木卫二 Europa、木卫三 Ganymede、木卫四 Callisto）实施引力助推机动实现减速入轨的物理可行性与推进剂节省效能。

研究结论表明：利用木星卫星引力助推减速以节省大量燃料的策略在物理原理与工程量级上均完全不成立，无法实现显著的燃料节省。 核心研究发现如下：

  1. 单次飞掠绝对减速量极为微弱：在航天器紧贴卫星表面（rp = Rmoon）顺行切向掠过的极端理想上界构型下，四颗伽利略卫星所能提供的最大理论减速量仅为 0.287 ∼0.514 km/s（其中引力最强的木卫三上限为 0.514 km/s，木卫一为 0.450 km/s，木卫四为 0.394 km/s，木卫二仅为 0.287 km/s）。
  2. 轨道能量未闭合导致引力自捕获彻底失效：探测器在卫星轨道高度被木星捕获所需的最小制动量高达 7.12 ∼11.52 km/s。即便经木卫三最大减速后，探测器的剩余双曲过剩速度仍高达 v∞,residual = 19.35 km/s，轨道比机械能 E > 0 维持极强双曲线形态，无法闭合为绕木星环绕轨道。
  3. 未入轨状态下多次引力助推完全无法实施：双曲线轨道具有单向穿越性。由于单次飞掠无法实现捕获，探测器在穿过木星系统后将直接永久逃逸至深空，绝无再次与任何卫星发生几何相遇或执行多次弹弓飞掠的机会。
  4. 联合近木点点火推进剂节省微不足道：若将卫星飞掠与近木点（rp = 1.05 RJ）奥伯斯特机动相结合，由于高双曲速度下卫星减速对近心点动能削减的几何边际效应递减，近木点捕获制动量仅能从基准的 3.346 km/s 降低至 3.138 km/s，净节省仅 0.208 km/s（相对脉冲节省率仅 6.25%，推进剂质量节省仅占整机湿重的 2.38%）。
  5. 现实工程惩罚导致净收益归零甚至为负：深空瞄准卫星所需的多次中途轨道修正（TCM）将消耗数十至上百米每秒的速度增量，且飞掠卫星后的出射渐近方向对近木点切向制动姿态带来严苛的几何失配约束，实际工程净收益被完全抵消。

综上所述，该策略既无法免除主减速推进系统，也无法带来有工程价值的燃料节省。

2. 引言与背景

在外行星深空探测任务中，探测器从地球转移至外行星时通常具有极高的相对日心速度。当探测器飞抵行星引力影响球（Sphere of Influence, SOI）边界时，其相对于目标行星具有显著的双曲过剩速度 v∞。若不施加制动机动，探测器将沿双曲线轨道掠过行星并重新逃逸至日心轨道。为实现环绕探测（Orbit Insertion），探测器必须大幅降低轨道机械能，使轨道由无界的双曲线转变为有界的闭合椭圆轨道。

题干原始表述如下：

当探测器抵达外层行星（如木星）时，必须减速才能进入轨道，这一过程会消耗大量燃料。有观点认为，抵达木星的航天器可利用木星的卫星实施引力助推机动来减速，从而节省燃料。请评估，对于一个以20公里/秒的速度抵达木星（接近木星系统）的航天器，能否通过该策略实现显著的燃料节省。

针对题干设定的 v∞ = 20 km/s 高速抵近工况，本研究旨在通过严格的二体与受限三体引力弹弓动力学建模，查明四颗主要伽利略卫星在双曲飞掠过程中的极限几何偏折能力，量化单次与多次飞掠减速上限，并与直接化学推进捕获需求进行对比，确立该方案的最终可行性结论。

3. 假设

为了构建既保持数学严谨性又具备工程代表性的解析动力学模型，本文确立以下六项物理假设：

  • 假设 1（球对称质点引力场）：木星与各卫星均视为球对称刚体质点，其引力场由标准牛顿万有引力常数 μ= GM 完整描述，忽略行星自转扁率引起的高阶引力摄动（如木星 J2, J4）及卫星潮汐形变次级效应。
  • 假设 2（卫星正圆共面开普勒运动）：四颗伽利略卫星（Io, Europa, Ganymede, Callisto）在木星赤道面内沿正圆开普勒轨道稳定公转，其轨道半长轴恒定，忽略卫星之间的拉普拉斯轨道共振偏心率微扰。
  • 假设 3（拼接圆锥曲线分层近似）：遵循天体动力学经典拼接圆锥曲线（Patched Conics）理论，探测器在木星影响球内按以木星为焦点的无摄双曲线轨道运行；当进入卫星影响球（Hill/SOI）后，瞬时切换为卫星质心系下的无摄双曲线散射；由于飞掠相遇时间（数小时）远小于卫星公转周期，飞掠期间卫星速度矢量视为恒定常矢量（脉冲渐近飞掠）。
  • 假设 4（表面物理避障安全下界）：为确保航天器安全，飞掠轨道近拱点半径不得低于卫星平均表面物理半径（rp ≥Rmoon），紧贴表面飞掠对应引力偏折与减速量的绝对物理理论上限。
  • 假设 5（顺行切向最优减速几何上界）：假设航天器以顺行轨道与卫星在公转轨道切点处相遇，并由卫星运动前方（Leading Edge）掠过，使散射出射速度矢量产生与木星公转速度完全反向的最大负向投影，从而给出对“减速策略”最有利的理论极限。
  • 假设 6（理想脉冲推进与奥伯斯特捕获）：轨道机动发动机点火视为瞬时切向冲量，双元化学推进系统有效比冲取深空标准公称值 Isp = 320 s（排气速度 c = Isp g0 ≈3.138 km/s），捕获基准位置取近木点表面上方安全高度（rp = 1.05 RJ）。

4. 建模与主推导

4.1 抵近木星系统的双曲能量与速度分布

本小节结论：在 v∞ = 20 km/s 条件下，由于木星强大的深引力势阱加速，探测器抵达各伽利略卫星轨道高度时的速度高达 23.1 ∼31.6 km/s，动能主要由木星引力势能转化贡献。

根据假设 1 与假设 3，探测器在木星影响球内的运动遵循开普勒二体双曲线轨道。轨道比机械能（Specific Orbital Energy）守恒：

EJ = 12 vJ2(r) - μJr = 12 v∞2

其中 μJ = 1.26686534 ×108 km3/s2 为木星标准引力常数，r 为探测器到木星中心的距离。解出距离木星中心 r 处的轨道速率（活力公式，Vis-Viva Equation）：

vJ(r) = √v∞2 + 2μJr

由假设 2，各卫星绕木星做正圆轨道运动，卫星公转半径等于轨道半长轴 am，公转线速度为：

vm = √μJam

将四颗伽利略卫星的公转半长轴代入计算：

  • 木卫一 (Io)：a1 = 4.217 ×105 km，公转速度 vm1 = 17.334 km/s，探测器到达速度 vJ(a1) = √202 + 2 ×1.26686534 ×108421700 = 31.636 km/s；
  • 木卫二 (Europa)：a2 = 6.709 ×105 km，公转速度 vm2 = 13.740 km/s，探测器到达速度 vJ(a2) = 27.887 km/s；
  • 木卫三 (Ganymede)：a3 = 1.0704 ×106 km，公转速度 vm3 = 10.880 km/s，探测器到达速度 vJ(a3) = 25.233 km/s；
  • 木卫四 (Callisto)：a4 = 1.8827 ×106 km，公转速度 vm4 = 8.204 km/s，探测器到达速度 vJ(a4) = 23.121 km/s。

4.2 卫星相遇运动学与相对渐近双曲速度下界

本小节结论：顺行切向飞掠构型提供了理论最小的相对相遇速度，该速度在各卫星处均稳定在 14.1 ∼14.9 km/s 区间，远超卫星自身引力逃逸速度。

当探测器进入卫星影响球时，其在卫星质心系下的相对速度矢量为：

v⃗∞,rel = v⃗J - v⃗m

由于引力助推产生的偏折角与相对速度的平方成反比，相对速度越小，引力偏转能力越强。因此，最优减速构型必须最小化相遇相对速度 |v⃗∞,rel|。

根据假设 5，探测器与卫星在共面切点处以同向顺行方式相遇，两速度矢量平行同向。此时相对速度模长达到绝对理论极小值：

v∞,rel,min = vJ(am) - vm

代入各卫星数据可得：

  • 木卫一：v∞,rel = 31.636 - 17.334 = 14.302 km/s；
  • 木卫二：v∞,rel = 27.887 - 13.740 = 14.147 km/s；
  • 木卫三：v∞,rel = 25.233 - 10.880 = 14.353 km/s；
  • 木卫四：v∞,rel = 23.121 - 8.204 = 14.917 km/s。

若相遇存在轨道交角（非切向相遇），相对速度将因包含径向分量 vr 而显著增大，飞掠减速能力将进一步恶化。

4.3 双体双曲散射动力学与最大引力偏转角

本小节结论：受限于卫星有限的质量与表面物理半径约束，卫星对 14 km/s 相对速度的航天器散射偏转能力极弱，渐近偏折角仅在 1.16∘ ∼2.05∘ 之间。

在卫星质心参考系中，探测器受卫星万有引力作用沿无摄双曲线轨道运动。设双曲线近拱点距离为 rp，由角动量守恒与机械能守恒可导出双曲线轨道的离心率 e 表达式：

e = 1 + rp v∞,rel2μm

4.4 木星质心系速度矢量衰减与最大理论减速量

本小节结论：在最优反向减速构型下，单次飞掠所能产生的木星系速度衰减上限为 |Δv⃗J| = 2 v∞,rel sin(δ/2)，其数值在四颗卫星中最大仅为 0.514 km/s（木卫三）。

在卫星质心系中，由于弹性散射守恒，出射相对速度与入射相对速度大小相等：

|v⃗∞,out| = |v⃗∞,in| = v∞,rel

两渐近速度矢量之间的几何夹角即为偏转角 δ。卫星质心系内的速度变化矢量模长为：

|Δv⃗| = |v⃗∞,out - v⃗∞,in| = 2 v∞,rel sin(δ2) = 2 v∞,rel1 + rp v∞,rel2μm

转换至木星质心参考系中，飞掠后的木星系速度矢量为 v⃗'J = v⃗m + v⃗∞,out。飞掠前后的速度矢量差完全源于相对速度矢量的变化：

Δv⃗J = v⃗'J - v⃗J = v⃗∞,out - v⃗∞,in = Δv⃗

根据向量三角形模长不等式，木星系标量速率的衰减量满足绝对上界：

Δvdecel = vJ - |v⃗'J| ≤|Δv⃗J| = 2 v∞,rel1 + rp v∞,rel2μm

当且仅当出射相对速度 v⃗∞,out 旋转至与卫星运动方向完全反向时，等号严格成立。

计算四颗卫星的最大理论速度降低绝对上限：

  • 木卫一：|Δv⃗J,1| = 2 ×14.302 ×0.015744 = 0.4503 km/s；
  • 木卫二：|Δv⃗J,2| = 2 ×14.147 ×0.010149 = 0.2872 km/s；
  • 木卫三：|Δv⃗J,3| = 2 ×14.353 ×0.017895 = 0.5137 km/s；
  • 木卫四：|Δv⃗J,4| = 2 ×14.917 ×0.013209 = 0.3941 km/s。

4.5 木星引力捕获的速度增量需求与奥伯斯特效应

本小节结论：航天器实现闭合轨道捕获在卫星高度直接制动需要 7.12 ∼11.52 km/s；利用木星表面近木点奥伯斯特效应最小制动需求为 3.346 km/s。引力助推减速量与捕获需求存在整整一个数量级的鸿沟。

捕获机动的物理本质是将开普勒总能量由正值（双曲线）削减至零（临界抛物线）或负值（椭圆）：

E = 12 v2 - μJr ≤0

临界捕获速度即为当地逃逸速度 vesc(r) = √2μJr。所需最小制动速度增量为：

Δvcap(r) = vJ(r) - vesc(r) = √v∞2 + 2μJr - √2μJr

对比两类捕获路径：

  1. 卫星轨道高度直接捕获（无近心点俯冲）：
  • 木卫一轨道处：vesc = 24.514 km/s，vJ = 31.636 km/s impliesΔvcap = 7.122 km/s；
  • 木卫三轨道处：vesc = 15.389 km/s，vJ = 25.233 km/s impliesΔvcap = 9.844 km/s；
  • 木卫四轨道处：vesc = 11.602 km/s，vJ = 23.121 km/s impliesΔvcap = 11.519 km/s。
  1. 近木点奥伯斯特捕获（经典高效深空路径）：

根据奥伯斯特效应（Oberth Effect），在深势阱底部高速运动时施加切向推力，动能变化率 dEdt = F⃗ ·v⃗ 最大。取近木点高度为木星云顶上方 1.05 RJ（rp = 75067 km）：

vesc(rp) = √2 ×1.26686534 ×10875067 = 58.097 km/s
vJ(rp) = √202 + 58.0972 = √400 + 3375.29 = 61.443 km/s
Δvcap,min = 61.443 - 58.097 = 3.346 km/s

4.6 齐奥尔科夫斯基推进剂质量比模型

本小节结论：飞掠减速在近木点制动中仅能减少 0.208 km/s 的发动机点火需求，对应推进剂消耗仅降低 2.38% 整机湿重。

若先飞掠木卫三获得最大速度衰减，出射后探测器的剩余双曲过剩速度降低为：

v'J(rp) = √19.3482 + 58.0972 = 61.235 km/s

在近木点捕获所需的新制动增量为：

Δv'cap = 61.235 - 58.097 = 3.138 km/s

δ(Δv) = 3.346 - 3.138 = 0.208 km/s

η= 0.2083.346 ≈6.22%

由假设 6，根据齐奥尔科夫斯基火箭方程，制动消耗的推进剂占整机初始质量（湿重）的比例为：

ζ= mpropm0 = 1 - exp(-ΔvIsp g0)

5. 验证

5.1 量纲齐次性检验

本小节结论：双体双曲散射速度变化量方程通过了严格的物理量纲齐次性验证，所有加和单项式的物理量纲严格统一为 [L]4 / [T]3。

为排查公式推导中的代数错误与量纲失配，将引力助推减速控制方程：

Δv = 2 μm v∞,relμm + rp v∞,rel2

转化为无分母加和的多项式单项式展开形式：

Δv ·μm + Δv ·rp v∞,rel2 = 2 μm v∞,rel

采用专业量纲引擎核验各独立物理量的量纲属性：

  • 速度增量 Δv 与渐近速度 v∞,rel：[L]/[T]（速度量纲，m/s）；
  • 近拱点距离 rp：[L]（长度量纲，m）；
  • 卫星引力常数 μm：[L]3 / [T]2（引力参数量纲，m3/s2）。

对多项式展开式中的三项逐一计算量纲积：

  1. 第一项 Δv ·μm：([L]/[T]) ×([L]3/[T]2) = [L]4 / [T]3；
  2. 第二项 Δv ·rp v∞,rel2：([L]/[T]) ×[L] ×([L]/[T])2 = [L]4 / [T]3；
  3. 第三项 2 μm v∞,rel：([L]3/[T]2) ×([L]/[T]) = [L]4 / [T]3。

三项量纲完全一致，无量纲不一致项，且式中超越函数（反正弦 arcsin）自变量严格无量纲（分母中 rp v∞2 / μm 量纲为 [L] ×[L]2/[T]2 div([L]3/[T]2) = 1），量纲门禁完全通过。

若要获得数千米每秒的显著减速（例如达到 Δv > 3 km/s），相对相遇速度必须低于 2 ∼3 km/s，这在双曲过剩速度高达 20 km/s 的入射轨道上完全违背机械能守恒。

6.3 轨道能量未闭合与多次引力助推失效机制

本小节结论：单次飞掠后航天器剩余能量仍然为极大的正值，轨道依然是开放的双曲线，探测器将一次性永久穿出木星系统，绝无执行多次飞掠的可能。

部分观点推测能否通过“连续飞掠多颗卫星（例如依次飞掠木卫四、木卫三、木卫二、木卫一）”实现累积减速。天体动力学分析证明该设想在物理上完全无法实现：

  1. 轨道能量判据：捕获的充要条件为比机械能 E ≤0。由表 1 可知，探测器经木卫三飞掠减速后，其剩余双曲过剩速度仍高达 v∞,residual = 19.35 km/s，对应的轨道能量为 E = +187.2 km2/s2 ≫0。
  2. 拓扑开闭性：正能量轨道在几何拓扑上是一条无界双曲线，具有唯一的近心点与两条向无穷远处延伸的渐近线。探测器一旦掠过近木点，将沿出射渐近线直奔深空，永远不会返回。
  3. 共振相遇不可达：多重引力助推巡航（如旅行者号、卡西尼号、朱诺号任务）的前提是航天器已经处于受闭合束缚的椭圆轨道上，通过轨道周期与卫星周期的整倍数共振实现周期性再相遇。对于处于开轨道的逃逸探测器，其在木星系统内的停留时间仅为数十小时，各卫星在各自轨道上的空间公转相位完全分散，几何上不存在单次无摄双曲线能同时精确切向相交多颗卫星轨道的空间轨迹。

6.4 联合近心点奥伯斯特机动的工程推进剂核算

本小节结论：飞掠减速在最优工程构型下仅能节省 6.25% 的捕获速度增量，折合整机推进剂质量占比仅下降 2.38%，无法改变推进系统干湿质量架构。

以目前深空探测最成熟的联氨/四氧化二氮双元双推化学动力系统（比冲 Isp = 320 s）进行定量核算：

  • 纯化学推进基准：直接在近木点 rp = 1.05 RJ 实施制动，需消耗脉冲 Δv = 3.346 km/s，推进剂质量比为 65.57%。对于一颗初始湿重为 2000 kg 的探测器，需消耗推进剂 1311.4 kg，入轨后干重仅剩 688.6 kg。
  • 卫星飞掠辅助推进：飞掠木卫三后至近木点制动，所需脉冲降为 Δv = 3.138 km/s，推进剂质量比为 63.19%，推进剂消耗为 1263.8 kg。
  • 净节省量：推进剂净节省为 47.6 kg（仅占湿重的 2.38%）。

考虑到为了在抵近前数百万公里处精确对准卫星边缘以实现 1.0 Rmoon 紧贴飞掠，探测器必须执行 2 ∼3 次深空中途轨道修正（Trajectory Correction Maneuvers, TCM），消耗的修正推进剂达数十米每秒；此外，飞掠产生的平面外偏转角会破坏近木点制动时推力方向与轨道速度的完美切向对齐度，引入余弦投影推力损失。扣除上述工程损耗后，净节省几乎归零。

7. 理论假设与适用局限

7.1 模型优势与物理刚性

本研究采用天体动力学极限上界分析法，其核心优势在于构建了对“引力助推减速”最为有利的理论极端场景：

  1. 几何极值包络：模型假设了绝对顺行共面切向相遇（相对速度取最小值）、紧贴卫星物理表面飞掠（近拱点取最小值 rp = Rmoon）、出射速度完全反向投影（动量衰减取最大值）。在自然界中，实际飞掠由于轨道倾角、偏心交角与安全避障高度的存在，所能获得的减速量必然严格小于该理论上限。
  2. 结论的刚性与不变量：在此极端理想上界下，四颗卫星所能提供的最大减速量（最高仅 0.514 km/s）仍与捕获需求（3.346 ∼11.52 km/s）存在数倍至数十倍的刚性差距。这证明“无法通过该策略实现显著燃料节省”是一项不依赖于精细轨道摄动或具体参数微调的第一性物理定律结论，具有绝对的物理稳健性。

7.2 简化假设的适用范围与失效边界

明确界定本模型的适用范围（Regimes of Validity）与物理失效边界：

  1. 拼接圆锥曲线（Patched Conics）的适用边界：

本模型采用二体拼接圆锥曲线法，忽略了卫星希尔球交界面外的木星引力梯度二阶潮汐摄动。对于以 14 km/s 穿越卫星影响球的高速航天器，其在卫星附近停留的时间仅为数小时，卫星相对木星的位移弧长极短，三体摄动加速度与卫星点源引力加速度之比在希尔球内部小于 1%。全数值限制性三体问题（CR3BP）积分表明，摄动引起的修正量通常在 10-3 ∼10-2 km/s 量级，完全不影响亚千米每秒的主导结论。

  1. 工程避障与导航误差的现实约束：

假设 4 允许航天器紧贴卫星表面（0 km 高度）掠过。然而在深空工程实践中，由于地球与木星间数十光分的通信时延，探测器在执行飞掠时必须依靠自主光学导航与地基无线电定轨。受限于轨道确定协方差与中途轨道修正精度，实际任务必须设置至少数百公里（通常为 200 ∼500 km）的安全避障走廊。若近拱点提升至 Rmoon + 300 km，木卫三的减速量将进一步萎缩至 0.46 km/s。

  1. 无大气与热防护假设：

四颗伽利略卫星均为无显著浓密大气的岩石/冰质天体（仅木卫一有极其稀薄且空间不均的二氧化硫火山逸散层，表面气压仅约 10-7 Pa），无法提供气动升阻力。因此，航天器无法借助任何大气减速（Aerocapture）机动，完全受制于牛顿万有引力的纯保守场特性。

8. 讨论与未来方向

8.1 为什么历史真实木星任务能够频繁利用卫星引力助推

航天工程史上著名的木星系统探测器（如伽利略号 Galileo、卡西尼号 Cassini 飞掠木星、朱诺号 Juno 以及正在执行的欧罗巴快船 Europa Clipper），在其任务周期内均对伽利略卫星开展了数十次极其成功的引力助推变轨。这一事实常导致公众甚至部分工程师产生“抵近木星时利用卫星减速即可入轨”的直觉误区。

天体动力学分析指出了这两者之间存在根本性的轨道拓扑差异：

  • 历史真实任务的先决条件是“先闭合轨道”：伽利略号在 1995 年抵达木星时，首先依靠其主发动机在近木点进行了长达 46 分钟、耗费 Δv = 643 m/s 的强力点火，同时配合了木卫一的微弱引力辅助，其核心目的是先将原本开放的双曲线轨道闭合为一条绕木星运转、周期约 200 天的初始大椭圆轨道；
  • 闭合轨道内的共振累积效应：只有当探测器成为木星的束缚人造天体后，轨道机械能转为负值，探测器才会周期性地返回近木点。导航团队利用轨道周期与卫星公转周期的有理数共振（Resonance），在随后长达 8 年的扩展任务中，通过多达 35 次顺次安排的卫星飞掠，每次调节数十至上百米每秒的速度矢量，最终逐步将远木点从数千万公里降低至数百万公里，并实现了对不同卫星的变倾角探测；
  • 开放轨道的单次逃逸特性：相反，本题所针对的是处于 v∞ = 20 km/s 超强双曲线上的未捕获航天器。单次飞掠无法弥补数千米每秒的捕获能量缺口，轨道无法闭合，因此根本不存在第二次与卫星相遇的可能。

8.2 低能量捕获与弱稳定性边界拓展探讨

若将题干条件放宽，探讨入射速度对该策略可行性的临界分岔阈值：

  1. 渐近低速极限（v∞ →0）：

若航天器采用霍曼转移或多次内行星引力弹弓（如借力金星和地球），将抵达木星影响球边界时的相对过剩速度降低至接近于零（v∞ ≈0.5 ∼1.5 km/s），此时间接切向相遇相对速度将大幅降低至 v∞,rel ≈2 ∼3 km/s。此时无量纲特征数 Π 降至接近 1，偏转角可达数十度，单次飞掠减速量有望提升至 1.5 ∼2.5 km/s。结合太阳-木星系统的外拉格朗日点（L1, L2）弱稳定性边界（Weak Stability Boundary, WSB）与不变流形（Invariant Manifolds），理论上有可能实现极低推进剂消耗的弹道自捕获（Ballistic Capture）。

  1. 高超能区的必然局限：

然而，对于题干明确给定的 v∞ = 20 km/s 而言，探测器具有极高的比动能（200 MJ/kg），系统远远偏离了弱稳定性边界的引力混沌敏感区，完全处于确定性的双曲动力学主导能区。

8.3 高速抵近外行星的真正工程破局路径

对于必须以超高过剩速度抵近木星等外行星的未来深空探测任务，要显著降低燃料消耗，物理可行的前沿工程途径包括：

  1. 木星高层大气减速捕获（Aerocapture）：

利用探测器配备的高性能气动热防护罩（如碳基烧蚀隔热罩或可展开式充气减速结构 HIAD/ADEPT），精准切入木星稀薄高层大气（高度约 300 ∼400 km）。利用大气粘性阻力在数分钟内一次性消耗掉 3 ∼4 km/s 的多余动能，出大气层后仅需微弱发动机点火抬高近心点即可完成捕获。该技术可将推进系统质量占比从 65% 骤降至 10% 以下；

  1. 先进核热推进（Nuclear Thermal Propulsion, NTP）：

采用浓缩铀反应堆加热液氢推进剂，比冲可达 900 ∼1000 s，使有效排气速度提升至 9 ∼10 km/s。在相同的 3.35 km/s 捕获速度增量下，由齐奥尔科夫斯基方程计算的推进剂质量占比将从化学动力的 65.6% 下降至 29%，从动力系统源头攻克外行星入轨减速的“燃料诅咒”。
