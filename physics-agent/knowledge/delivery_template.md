```text
### 【本项目高可靠性物理研究架构设计说明】

为彻底解决大语言模型在复杂科学计算与物理工程分析中常见的“符号幻觉”、“虚构公式”、“量纲混乱”及“代码伪执行”等不可靠问题，本项目设计了一套严谨的工程化、确定性研究流水线与质量防御体系：

1. **单源真理状态机驱动（SSOT State Machine）**：
   - 整个研究过程由强类型的物理状态账本（`problem_state.json`）统一管理；
   - 所有物理常数、控制方程、边界假设、运行记录及门禁审查结论均实现确定性持久化，从根本上杜绝多轮会话中的上下文漂移与记忆遗忘。

2. **三级计算与工具资产分级（Three-Tier Asset Governance）**：
   - 将数值计算严格划分为“通用数学库（Tier 1）”、“针对本课题定制编写的高精度数值仿真模型（Tier 2，如四阶龙格-库塔变步长数值积分与打靶法）”以及“领域规范与绘图组件（Tier 3）”；
   - 所有数值结论必须由真实 Python 解释器执行落盘，严禁模型凭空捏造计算结果。

3. **四重自动化刚性质量防御门禁（Four Rigid Quality Defense Gates）**：
   - **量纲齐次性门禁（Gate 1）**：基于 Pint 物理量纲体系对所有控制方程与派生公式进行机器自动化校验，物理量纲不自洽的推导一律拦截；
   - **边界极限与退化验证门禁（Gate 2）**：将模型推导推向极端物理边界（如零阻力真空退化、极端初速、极端发射角等），确保理论解在退化工况下精准退化为经典解析解；
   - **数据源可靠性决断（Gate 3）**：明确区分理论第一性原理推导、标准物性参数库查验与外弹道经验模型，对环境扰动进行多阶泰勒微扰建模；
   - **出厂前学术质量刚性审查（Gate 4）**：在报告交付前自动执行 8 维综合质检，刚性拦截模型自夸、内部开发术语黑话、未编译标记、死链及未定义图表。

4. **100% 离线自包含学术出版引擎**：
   - 交付产物为内联全部公式渲染引擎的单文件双栏 HTML 学术报告，彻底脱离外部 CDN 依赖；
   - 包含外置 Flex 胶囊图例条（曲线零遮挡）、右侧常驻代码/运行记录预览窗格，以及会话全时序轨迹毫秒级交互热跳转功能，实现理论研究全过程的可重现与可审计。
```
