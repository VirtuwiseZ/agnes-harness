# 物理竞赛与仿真数据源权威指引 (Physics Simulation Data Sources Guide)

> **定位与职责**：本项目在大学生物理竞赛（UPC）、科研建模与工程仿真中**获取外部客观参数与基准数据**的唯一权威操作指南。
> **适用节点**：由 `.agh/skills/physics-pipeline/SKILL.md` 的 **Node 1.5（数据源路由与获取）** 直接指向并强制执行。
> **编制依据**：结合 2010–2025 年历届金牌论文数据源分析、开发者实际诉求，以及 2026-10-13 在真实网络环境下对全球主流科学数据库的**实测连通性结果**。

## 第二部分：按物理领域分类的详细数据源名录与代码接入模板

### 1. 天体物理与星际轨道动力学 (Astrophysics & Orbital Mechanics)
- **NASA JPL Horizons API**：
  - *URL*: `https://ssd-api.jpl.nasa.gov/horizons.api`
  - *适用场景*: 太阳系星体瞬态相对位置、开普勒六根数、引力助推计算、拉格朗日点定位。
- **NASA JPL Small-Body Database (SBDB)**：
  - *URL*: `https://ssd-api.jpl.nasa.gov/sbdb.api?sstr=小行星编号`
  - *适用场景*: 小行星撞击防御、轨道偏转、近地天体偏心率与反照率。
- **NASA NSSDC Planetary Fact Sheets**：
  - *URL*: `https://nssdc.gsfc.nasa.gov/planetary/factsheet/`
  - *适用场景*: 行星与天然卫星标准常数表（质量 $M$、赤道半径 $R$、引力参数 $GM$、自转周期）。

### 2. 空气动力学与流体/高空大气 (Aerodynamics & Atmosphere)
- **US Standard Atmosphere 1976 (`ambiance` 库，第一档)**：
  - *适用场景*: 0–86 km 范围内的对流层/平流层连续温度 $T(z)$、气压 $P(z)$、密度 $\rho(z)$、声速 $a(z)$。
- **NRLMSIS-00 / 2.1 高空大气模型 (`pymsis` 库，第一档)**：
  - *适用场景*: 86–1000 km 极高空变温变密度热层与外大气层，用于航天器再入与极限太空跳伞。

### 3. 热力学、相变与材料物性 (Thermodynamics & Materials)
- **NIST Chemistry WebBook (第一档)**：
  - *URL*: `https://webbook.nist.gov/chemistry/`
  - *适用场景*: $\text{CO}_2$、水蒸气、甲烷等气体的 Shomate 拟合比热容公式、相变焓。
- **CODATA 基础物理常数 (`scipy.constants`，第一档)**：
  - *适用场景*: 引力常数 $G$、玻尔兹曼常数 $k_B$、光速 $c$、普朗克常数 $h$。
- **PubChem PUG REST API (第一档)**：
  - *URL*: `https://pubchem.ncbi.nlm.nih.gov/rest/pug/`
  - *适用场景*: 化合物相对分子质量、标准密度、热力学物性一键查询。

### 4. 地球物理、空间天气与太阳活动 (Geophysics & Space Weather)
- **NOAA 空间天气预测中心 API (第一档)**：
  - *URL*: `https://services.swpc.noaa.gov/json/planetary_k_index_1m.json`
  - *适用场景*: 太阳风暴对近地轨道卫星电离层阻力的扰动、地磁 Kp 指数。
- **SIDC 太阳黑子长期序列 (`physics-agent/knowledge/reference_data/sidc_sunspot_monthly_1749-2026.csv`，第一档)**：
  - *适用场景*: 太阳 11 年活动周期与长周期辐射通量演化。

## 第三部分：Skill 联动规则与标准操作流程 (SOP)

为使本指引在真实解题中得到自动化落实，在 `.agh/skills/physics-pipeline/SKILL.md` 的 **Node 1.5** 阶段必须强制执行以下**数据源决策 SOP**：

```
[Node 1.5 数据源路由 SOP]
  1. 首先判断所需数据属于哪个物理大类；
  2. 优先检查「第一档」中是否有现成的本地 Python 库 (Level 0) 或本地 CSV 数据集 (Level 2)；
     → 若有，直接在代码中 import 或相对路径读取，零网络开销，最可靠；
  3. 若必须从外部拉取，查阅「第一档」的官方公开 REST API：
     → 检查当前网络连通性；若遇到 Fake-IP 拦截，优先使用 Python OS 网络栈直连脚本（见 network_and_vpn_guidelines.md）；
  4. 若所需数据属于「第二档」（商业学术论文、电商实物参数、复杂视频打点）：
     → 立即触发人机协作流程（Fault-tolerance Option A）：向用户清晰说明所需物理量的名称与推荐渠道，
       等待用户人工查阅后回传数值；
  5. 严禁凭空捏造未经验证的真实物理观测数据，严禁在缺乏数据时静默跳过验证！
```
